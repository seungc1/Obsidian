# 7. Attachments

## 목적과 역할

이미지, PDF 등 **바이너리 첨부 파일**을 모아두는 폴더입니다. 마크다운 노트와 바이너리 파일을 분리해 Vault 구조를 깔끔하게 유지합니다.

## 어떤 노트가 들어가는가

- 이미지 (`.png`, `.jpg` 등), PDF, 기타 첨부 문서
- 마크다운 파일은 두지 않음

## 작업 방식과 규칙

1. 모든 첨부 파일은 이 폴더에 두고, 원본 노트에서는 `![[파일명]]`으로 임베드
2. 파일명은 충돌을 피하기 위해 의미 있는 이름 사용 (필요시 날짜 접두사)
3. 대용량 파일(PDF, 동영상 등)이 많아지면 Git LFS 사용을 고려
4. 더 이상 어떤 노트에서도 참조되지 않는 첨부 파일은 정기적으로 정리
