# 1. Projects

## 목적과 역할

**명확한 목표와 마감일이 있는** 작업을 관리하는 폴더입니다. PARA 시스템에서 가장 시간 압박이 큰 카테고리로, "완료"라는 종료 조건이 존재하는 모든 작업이 여기에 속합니다.

Zettelkasten(`5. Zettelkasten/`)이 시간과 무관한 지식을 쌓는 곳이라면, 이 폴더는 **실행과 산출물**을 위한 작업대입니다.

## 어떤 노트가 들어가는가

- 프로젝트 허브 노트 (`type: project`) — 프로젝트별로 1개씩, 목표·마감일·하위 태스크·관련 링크를 정리
- 프로젝트 진행 중 생성되는 작업 노트, 회의록, 산출물 초안
- 예시: "웹사이트 리뉴얼", "논문 작성", "이사 준비"

허브 노트가 아닌 세부 기록(회의록 등)은 프로젝트 하위에 파일로 두거나, 허브 노트에서 링크로 연결합니다.

## 작업 방식과 규칙

1. **프로젝트 시작 시** 허브 노트를 생성하고 `project` 템플릿(`6. Templates/`) 사용
2. 필수 속성: `type: project`, `status`, `created`, `due`
3. 지식/개념이 필요하면 **복사하지 말고** `5. Zettelkasten/20. Permanent/`의 퍼머넌트 노트를 `[[링크]]`로 참조
4. 반대로 프로젝트 수행 중 얻은 재사용 가능한 통찰은 Permanent Note로 승격시켜 Zettelkasten으로 이전
5. **프로젝트 종료 시** `status: completed`로 변경 후 `4. Archive/`로 이동
