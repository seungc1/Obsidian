# 폐점 재계약 리스크 조기경보 모델

## 목표(Outcome)
- 팀 미니프로젝트에서 담당한 데이터 수집·모델링 워크스트림
- 브랜드 고유 데이터 없이도 동작하는 일반화된 "폐점 + 재계약 실패" 통합 리스크 스코어 모델 개발

## 완료 기준(Definition of Done)
- [ ] Cell 단위(행정동x업종중분류x연도) 프록시 라벨 테이블 완성
- [ ] 일반화 피처(상권 활력도/경쟁밀도/유동인구/임대료/입지/생존곡선/프랜차이즈 base rate) 엔지니어링 완료
- [ ] LightGBM 기반 위험 스코어 모델 학습 + 캘리브레이션
- [ ] decile/calibration 검증 및 subgroup(업종/지역) 안정성 확인
- [ ] `pipeline.py`로 신규 점포 입력 -> 위험 스코어 출력 확인
- [ ] 팀 발표용 최종 리포트 작성(프록시 라벨 한계 명시)

## 범위/비범위
- **In scope:** 공공데이터 기반 일반화 모델, 분석 리포트, 재사용 가능한 예측 파이프라인
- **Out of scope:** 브랜드별 실측 데이터 기반 모델 (데이터 미확보), 실서비스 배포

## 핵심 설계 요약
- 타겟: 폐업/철수 OR 재계약 실패를 하나의 "사업 중단" 리스크 스코어로 통합
- 라벨: 국세청 휴폐업률(A) + 상권정보 상가업소 스냅샷 diff(B, 아래 리스크 참고) + 정보공개서 해지율(C)을 가중합한 Cell 단위 프록시(soft label)
- 모델: LightGBM 메인 트랙 + 캘리브레이션, 여유 시 lifelines 생존분석 보조 트랙
