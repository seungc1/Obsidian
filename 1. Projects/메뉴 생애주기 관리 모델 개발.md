7개 채택 소스를 기능정의서 §6 아키텍처(태그매칭→LLM곡선→임계값엔진→원가엔진)에 실제로 대조. **명확히 필요**: 네이버트렌드(임계값 엔진 유일 입력)/KAMIS(원가엔진 유일 입력)/특일정보/BOM·자사판매데이터(백테스트 전제). **재검토 여지**: (1) KMA 중기예보는 11일치만 제공하는데 모델은 수개월 곡선을 다뤄 실제 소비처가 불분명(계절신호는 특일정보가 이미 커버), (2) KOSIS/서울추정매출(지역보정)은 §0-3에서 지역군집 분리 자체를 보류해놓고 지역 보정계수만 살려둔 게 일관성이 없어 보임 — 목표고객사 미정인 지금 Phase 2로 같이 미룰 후보, (3) 농식품부/농진청 리포트는 신규 후보인 배민 트렌드 리포트(메뉴명 단위, 더 최신)와 역할이 겹침. 신규 후보 3개 중 SGIS·공정위 API는 §6 어디에도 지금 꽂을 자리가 없어 지금 붙이면 과설계 — 백로그 보류 권장, 배민 리포트만 농식품부 대체재로 검토 가치. 상세: [[3. ### 2026-07-31 (계속) — KMA 중기예보 제외 확정
필요성 재검토(§7) 결과에 따라 사용자 확인 하에 KMA를 채택 소스에서 최종 제외. 기능정의서 §5 데이터 입력 표(KMA 행 삭제, 특일정보만 유지)·§6 관련기능 연계(FUNC-004-06 연동 목록에서 KMA 제거)·§11 반영 완료. 데이터 소스 점검 문서도 §1(채택 7→6)·§2(제외 사유 추가)·§3(지역 해상도 표) 동기화. DoD 체크리스트의 "6종 API 확보"도 "5종"으로 정정.

### 2026-07-31 (계속) — 지역 보정계수 2종(KOSIS·서울추정매출) Phase 2 이연 확정
필요성 재검토(§7)에서 제기한 일관성 문제 — §0-3에서 지역군집 분리는 목표고객사 확정 전까지 보류해놓고 지역 보정계수만 먼저 연동하는 게 앞뒤가 안 맞는다는 지적 — 을 사용자 확인 하에 그대로 반영. KOSIS 서비스업동향조사·서울 열린데이터광장 추정매출 둘 다 Phase 2로 이연, MVP는 지역 보정 없는 단일 전국 곡선으로 진행. 기능정의서 §4 설계원칙3·§5 데이터 입력 표·§9 예외처리 반영 완료. 데이터 소스 점검 문서에 신규 §1-b(Phase 2 이연 데이터) 섹션 생성, §3·§4·다음액션도 동기화. DoD의 API 확보 항목도 "5종"→"3종"(특일정보/네이버트렌드/KAMIS)으로 정정. 두 소스 자체는 여전히 무료·즉시 발급 가능하므로 Phase 2 재검토 시 그대로 재사용 가능.
