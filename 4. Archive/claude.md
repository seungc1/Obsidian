# 4. Archive

## 목적과 역할

완료되었거나 더 이상 활성 상태가 아닌 PARA 항목의 보관소입니다. 삭제하지 않고 **이력으로 남겨** 필요할 때 다시 찾아볼 수 있도록 합니다.

## 어떤 노트가 들어가는가

- 완료된 프로젝트 (`1. Projects/`에서 이동, `status: completed`)
- 중단/비활성화된 영역 (`2. Areas/`에서 이동, `status: archived`)
- 더 이상 참고하지 않는 자료 (`3. Resources/`에서 이동)

Zettelkasten의 노트(Inbox/Literature/Permanent)는 이곳으로 이동하지 않습니다 — 지식은 시간과 무관하므로 항상 `5. Zettelkasten/`에 유지됩니다.

## 작업 방식과 규칙

1. 원본 폴더 구조를 유지하며 이동 (예: 프로젝트는 프로젝트 하위 폴더 형태 그대로)
2. 이동 시 `status`를 `completed` 또는 `archived`로 갱신하고 `updated` 날짜 기록
3. Archive 내부에서는 새 노트를 생성하지 않음 — 오직 이동된 항목만 존재
4. 다시 활성화가 필요하면 원래 폴더(Projects/Areas/Resources)로 되돌리고 `status`를 갱신
5. **분기 1회** Archive로 이동할 항목이 있는지 Projects/Areas/Resources를 검토
