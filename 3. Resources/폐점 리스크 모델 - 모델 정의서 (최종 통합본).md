# 폐점 리스크 관리 AI 모델 정의서 (최종 통합본)

[[1. Projects/폐점 재계약 리스크 조기경보 모델]]의 v1/v2를 하나로 합쳐 정리한 최종 모델 정의서. 개별 상세 내용은 [[3. Resources/폐점 리스크 모델 - 모델 정의서 (v1)]], [[3. Resources/폐점 리스크 모델 - 모델 정의서 (v2)]], [[3. Resources/폐점 리스크 모델 - 최종 보고서 (팀 공유용)]] 참고.

## 1. 모델 설명

프랜차이즈 본사가 가맹점의 폐업·재계약 실패 위험을 사전에 식별해 예방조치와 재계약 조항 설계에 활용하도록 만든 조기경보 모델이다. 전국 브랜드 간 위험도를 비교하는 v1(RandomForest, 공정위 실측 가맹점 변동 타겟)과 서울 지역 매장 간 위험도를 비교하는 v2(LightGBM, 서울 열린데이터광장 실측 폐업율 타겟)로 나뉘며, 두 결과를 백분위로 합쳐 2×2 위험 등급과 SHAP 기반 조치 가이드를 제시한다. 산출값은 정밀한 폐업 확률이 아니라 상대적 위험 순위로 설계·해석해야 한다.

## 2. 초기 결과 및 평가

최초의 시군구×업종 매크로 통계 기반 대리 라벨은 서울 실측 폐업율과 상관관계가 사실상 없어(스피어만 0.03) 폐기했다. 이후 브랜드 실측 타겟으로 전환한 v1 베이스라인도 평균값 예측 대비 개선이 거의 없었고(순위상관 0.037), v2 역시 소규모 브랜드에서 예측이 실측 편차를 못 따라가는 과소적합이 확인됐다. 원인은 매크로 통계의 낮은 해상도와 표본 부족으로 진단되어, 이후 방법론 전환의 출발점이 됐다.

## 3. 모델 최적화 진행 사항

v1은 표본크기 가중, 경쟁밀도·배후인구 피처 추가를 거쳐 순위상관을 0.037에서 0.16대까지 끌어올렸고, 브랜드 개별 이력·본부 재무 등 커버리지 낮은 피처는 기각했다. v2는 정확 업종매핑 대형 브랜드로 검증 대상을 바꾼 뒤 상권변화지표·추정매출·유동인구·소비지출 피처를 더해 유의미한 개선을 확인했고, 업종 편중을 보정하는 가중치와 v1의 업종 피어평균 신호를 이식해 안정성을 높였다. 마지막으로 두 모델 각각 8개 알고리즘 비교와 20시드 재검증을 거쳐 v1은 RandomForest, v2는 LightGBM으로 정식 교체했다.

## 4. 최종 모델 및 성능 평가

v1은 RMSE 0.2333(베이스라인 대비 개선), 순위상관 약 0.15~0.18로 종합 순위상관은 약하지만 상하위 10% 매장 간 실측 해지율 차이는 2.75배로 뚜렷해 극단값 선별에는 실용적이다. v2는 정확 업종매핑 대형 브랜드 기준 순위상관 약 0.65~0.75로 HistGBR 대비 20개 시드 전부에서 우위(p<0.0001)를 확인했다. 두 모델은 서로 독립적으로 작동하며 결합 시 2×2 등급과 법무 검토용 조항 초안을 함께 제공하지만, 확률이 아닌 순위 참고용이고 서비스 업종(v1)·근사매핑 소형 브랜드(v2)는 신뢰도가 낮다는 한계가 있다.
