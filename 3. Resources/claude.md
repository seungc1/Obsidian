# 3. Resources

## 목적과 역할

특정 프로젝트나 영역에 즉시 속하지 않는 **주제별 참고 자료**를 모아두는 폴더입니다. 미래에 유용할 수 있는 관심사 기반 자료의 저장소입니다.

Zettelkasten의 Literature Note(`5. Zettelkasten/10. Literature/`)가 하나의 원천에서 뽑아낸 노트라면, Resources는 주제 단위로 자료를 묶어두는 더 넓은 단위입니다.

## 어떤 노트가 들어가는가

- 주제별 참고 자료 노트 (`type: resource`)
- 예시: "프로그래밍", "디자인", "요리 레시피 모음"

## 작업 방식과 규칙

1. 새 자료 노트는 `resource` 템플릿(`6. Templates/`) 사용
2. 필수 속성: `type: resource`, `status`, `created`
3. 관련 프로젝트/영역이 생기면 해당 노트에서 이곳을 `[[링크]]`로 참조 (복사 금지)
4. 개별 문헌에 대한 깊은 분석이 필요하면 `5. Zettelkasten/10. Literature/`에 별도 노트를 만들고 서로 연결
5. **3개월 이상 미사용** 자료는 Archive 이동을 검토
