# 2026 국가데이터 활용대회 2차 PPT - 목차2 활용데이터 및 방법론 상세

[[1. Projects/2026 국가데이터 활용대회 - 고령층 자산정책 2차심사 준비]] 2차 PPT 목차2 "활용 데이터 및 방법론" 파트의 페이지별 상세 구성안. [[3. Resources/2026 국가데이터 활용대회 2차 PPT 초안]]의 "2부. 데이터 및 방법론" 섹션을 3페이지 단위로 구체화한 버전. 심사위원이 문서로 판단하므로 슬라이드 발표용이 아니라 **글 분량을 줄이지 않고 상세 서술**하는 방향으로 작성.

원래 구성안(초안 4페이지 중 "고령층 4유형 분류체계·3중 교차검증" 상세)은 성격상 방법론 소개가 아니라 실제 분석 결과이므로 [[3. Resources/2026 국가데이터 활용대회 2차 PPT - 목차3 데이터분석 상세]]로 이관하기로 결정.

## Page 1 — 활용 데이터

**슬라이드 타이틀: 활용 데이터 개요**

**리드 문장 (상단 요약)**
> 가계금융복지조사는 고령 가구의 자산·소득 구조를 파악하는 데 가장 적합한 데이터이나, 시군구 단위 지역 변수가 없어 공간 분석이 불가능하다는 한계가 있다. 이를 보완하기 위해 SGIS·NICE평가정보·카드소비 데이터 등 자치구 단위로 수집 가능한 8종의 데이터를 추가로 결합하여 총 9종의 데이터를 분석에 활용하였다.

**본문 — 3개 카테고리로 구조화**

**① 분류기반 데이터** (고령층 유형 분류의 근거)
- **가계금융복지조사(2023·2024, SDC/한국은행·금융감독원)**: 가구별 소득·자산·부채 원자료. 고령층 4유형 분류의 핵심 기반 데이터로, 정부기준빈곤선·소득분위·자산분위 산출에 사용
- **노인실태조사(2023, 보건복지부)**: 식사 결핍, 우울 점수 등 삶의 질 지표. 분류된 B유형(자산소득불일치층)의 생활고를 실증하는 데 사용

**② 교차검증 데이터** (분류 결과의 실증·타겟팅)
- **신용정보_대출및연체(NICE평가정보, 2024)**: 자치구별 주택담보대출 잔액·연체율·이자율 → 부채압박 실태 검증
- **신용정보_소득(NICE평가정보, 2024)**: 자치구별 추정 연소득 → 현금흐름 취약성 검증
- **카드소비_서울(통합카드 4사, 2024)**: 자치구별 카드사용액 → 실제 소비 위축 여부 교차 검증
- **아파트단지별소비(통합·농협카드, 2024)**: 단지별 소비 패턴 → 관심사·추정소득 보조 지표
- **외식업물가_시군구(NICE평가정보, 2025.1)**: 지역별 생활물가 수준 → 실질 구매력 보정 참고자료

**③ 공간분석 데이터** (자치구 단위 정책 우선지역 도출)
- **SGIS 가구통계등록부(통계청SGIS, 2023)**: 자치구별 고령가구 주거 현황(가구수, 주거유형 등)
- **SGIS 주택통계등록부(통계청SGIS, 2023)**: 자치구별 노후건물비율 산출 → 주거고착지수 원자료

**하단 보조 설명 (선정 이유 명시)**
> 본 연구는 개별 데이터셋의 단순 나열이 아니라, "①분류(가계금융복지조사·노인실태조사) → ②교차검증(NICE·카드소비) → ③공간분석(SGIS)"의 역할이 다른 3단 데이터 구조로 설계하였다. 이는 자산-소득 불일치 문제를 통계적으로 규명(①)하고, 실측 금융·소비 데이터로 재검증(②)한 뒤, 정책이 실제로 투입될 수 있는 지역 단위로 구체화(③)하기 위함이다.

## Page 2 — 데이터 전처리 과정

**슬라이드 타이틀: 데이터 전처리 과정**

**리드 문장**
> 성격이 다른 9종의 데이터를 하나의 분석 파이프라인에서 다루기 위해 ①표본 필터링 ②이종 데이터 결합 ③척도 표준화의 3단계 전처리를 거쳤다.

**① 표본 필터링**
> 가계금융복지조사 전국 6,714가구 중 수도권여부 변수(='G1')를 기준으로 필터링하여 분석대상 표본을 수도권 1,788가구로 한정하였다. 전국 표본을 그대로 사용하지 않은 이유는, 이후 결합할 SGIS·NICE·카드소비 데이터가 서울(자치구) 단위로 수집되어 지역 특성을 반영한 교차분석이 가능한 범위가 수도권으로 제한되기 때문이다. 이를 통해 전국 단위의 통계적 대표성과 자치구 단위의 지역 분석 가능성 사이의 균형을 맞추었다.

**② 이종 데이터 결합 (자치구 단위 연계)**
> 가계금융복지조사에는 시군구 식별 변수가 존재하지 않아, 4유형 분류 결과(B유형 등)를 자치구 단위로 직접 매칭할 수 없다는 구조적 한계가 있다. 이를 해결하기 위해 개별 가구를 직접 지역에 매칭하는 대신, SGIS(주거현황)·NICE평가정보(소득·대출)·카드소비(서울) 데이터를 자치구 단위로 결합하여 "B유형이 밀집할 가능성이 높은 지역적 조건"을 간접적으로 추정하는 방식을 채택하였다. 즉 가구 단위 분석(4유형 분류)과 지역 단위 분석(취약지수)을 별도 트랙으로 구성한 뒤, 두 결과를 해석 단계에서 연결하는 구조다. 실거래가 데이터는 고령자 보유 주택만 필터링할 수 없다는 한계로 인해 이 결합 과정에서 제외하였다.

**③ 척도 표준화 (Min-Max Scaling)**
> 노후건물비율(%), 연소득(원), 대출잔액(원), 카드사용액(원) 등 단위와 분포가 전혀 다른 지표를 하나의 지수로 합산하기 위해, 서울 25개 자치구를 기준으로 Min-Max 정규화를 적용하였다.
>
> **표준화 공식**: 점수 = (해당 구 값 − 서울 최솟값) / (서울 최댓값 − 서울 최솟값) × 100
>
> 이 과정에서 소득·소비 관련 지표는 "값이 낮을수록 취약"하다는 해석과 지수의 방향(높을수록 취약)을 일치시키기 위해 방향을 반전(100 − 점수)하여 처리하였다. 또한 주거고착지수는 노후건물비율과 평균주거면적이라는 서로 다른 두 지표를 각각 가구수 가중평균으로 산출한 뒤 표준화함으로써, 단순 산술평균이 아닌 실제 가구 분포를 반영하도록 하였다.

**하단 요약 표**

| 전처리 단계 | 처리 내용                                            | 목적                 |
| ------ | ------------------------------------------------ | ------------------ |
| 필터링    | 전국 6,714가구 → 수도권 1,788가구                         | 지역결합 데이터와 분석 범위 일치 |
| 데이터 결합 | 가구단위(가계금융복지조사) + 지역단위(SGIS·NICE·카드소비)를 자치구 기준 연계 | 시군구 변수 부재 한계 보완    |
| 표준화    | Min-Max 정규화(0~100점), 소득·소비 지표 방향 반전              | 이종 지표의 단위 통일 및 지수화 |

## Page 3 — 분석 방법론 개요

**슬라이드 타이틀: 분석 방법론 개요**

**리드 문장**
> 전처리된 데이터를 바탕으로 "①분류 → ②입증·타겟팅 → ③제언"의 3단계 방법론을 순차적으로 적용하였다. 각 단계의 구체적인 산출 결과는 [[3. Resources/2026 국가데이터 활용대회 2차 PPT - 목차3 데이터분석 상세]](목차3)에서 상세히 다룬다.

**① 분류 방법론 — 소득·자산 3중 교차검증(MECE)**
> 고령 가구를 단일 기준이 아닌 3개 기준(정부기준빈곤선, 고령층 내부 소득분위, 자산분위)을 교차 적용하여 상호배타적(MECE)인 4개 유형으로 분류하는 방법론을 설계하였다. 이는 소득만 기준으로 삼는 기존 복지 통계 방식으로는 포착되지 않는 "자산은 많지만 현금이 없는" 계층을 통계적으로 분리해내기 위함이다.

**② 입증·타겟팅 방법론 — SHAP 변수중요도 + 공간 취약지수**
> 분류된 유형(특히 B유형)의 특성을 두 방향에서 검증하였다. 첫째, 머신러닝 기반 SHAP(SHapley Additive exPlanations) 분석을 통해 어떤 변수가 B유형 판별에 가장 크게 기여하는지 정량화하였다. 둘째, 전처리 단계에서 구축한 자치구 단위 표준화 지표를 가중합산하여 "주거-현금흐름 취약지수"를 산출, 정책 투입이 시급한 지역을 공간적으로 식별하였다.

**③ 제언 방법론 — 정책 시뮬레이션**
> B유형의 실측 데이터(n=187)를 기반으로 정책 개입 전·후의 가처분소득, 적자가구 비율, 수급자격 회복률 변화를 시뮬레이션하여 정책안의 기대효과를 정량적으로 제시하였다.

**하단 프로세스 흐름**
> [전처리된 데이터] → ① 3중 교차검증 분류(MECE) → ② SHAP 검증 + 공간 취약지수 산출 → ③ 정책 시뮬레이션 → [정책 제언]
