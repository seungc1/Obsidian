# 폐점·재계약 리스크 모델 — 공공데이터 소스 목록

[[1. Projects/폐점 재계약 리스크 조기경보 모델]]에서 사용할, **실제 존재를 웹 검색으로 확인한** 공공데이터 소스만 정리. URL 미확인/추정 소스는 제외.

## 요약 (핵심 3줄)
1. 상권/점포 개폐업, 사업자 휴폐업 상태, 가맹사업 정보공개서, 임대동향, 인구통계까지 필요한 소스 대부분이 공공데이터포털(data.go.kr) Open API로 확인됨
2. 특히 공정거래위원회 가맹정보공개서는 **API로 구조화 제공됨을 확인** — 크롤링 불필요 (기존 설계상 불확실성 해소)
3. 유동인구/상권분석 데이터는 서울시 한정 — 전국 일반화 모델 목표라면 지방 커버리지 공백에 유의
4. **(추가, 2026-07-21)** 상가업소 데이터는 개폐업 이력이 아니라 스냅샷 — 폐업 라벨링에는 시점별 스냅샷 diff가 필요, 과거 시점 추가 다운로드 선행 필요

> ⚠️ **2026-07-21 실제 다운로드 데이터 검사 후 수정**: 상가(상권)정보 CSV는 전국 17개 시도 확보 완료(`data/raw/sbiz/`, 약 274만 건)했으나, **개업일자/폐업일자/영업상태 컬럼이 없는 스냅샷 데이터**임을 확인함. 39개 컬럼은 상가업소번호·업종분류·주소·좌표 등 위치정보뿐. 폐업 추정은 서로 다른 기준연월 스냅샷 2개 이상을 diff해야 가능 — 자세한 내용은 `closure-risk-model/docs/design.md`의 "B 소스 방법론 수정" 참고. 현재는 `202603` 1개 시점만 있어 **과거 시점 스냅샷 추가 다운로드가 선행되어야 라벨 구성 가능**.
