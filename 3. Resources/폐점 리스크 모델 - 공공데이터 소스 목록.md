# 폐점·재계약 리스크 모델 — 공공데이터 소스 목록

[[1. Projects/폐점 재계약 리스크 조기경보 모델]]에서 사용할, **실제 존재를 웹 검색으로 확인한** 공공데이터 소스만 정리. URL 미확인/추정 소스는 제외.

## 요약 (핵심 3줄)
1. 상권/점포 개폐업, 사업자 휴폐업 상태, 가맹사업 정보공개서, 임대동향, 인구통계까지 필요한 소스 대부분이 공공데이터포털(data.go.kr) Open API로 확인됨
2. 특히 공정거래위원회 가맹정보공개서는 **API로 구조화 제공됨을 확인** — 크롤링 불필요 (기존 설계상 불확실성 해소)
3. 유동인구/상권분석 데이터는 서울시 한정 — 전국 일반화 모델 목표라면 지방 커버리지 공백에 유의
4. **(추가, 2026-07-21)** 상가업소 데이터는 개폐업 이력이 아니라 스냅샷 — 폐업 라벨링에는 시점별 스냅샷 diff가 필요. **(2026-07-23 해결)** 과거 시점 10개 분기 확보 완료, 좌표+상호명 퍼지매칭으로 diff해 매장 단위 생존/폐업 실측 라벨 완성
5. **(추가, 2026-07-22)** 국세청 사업자상태조회 API는 개별 조회 전용 — Cell 단위 A 소스는 사업자현황 100대 생활업종 API로 대체 확정
6. **(추가, 2026-07-22)** 신규/폐업 분리 역산은 데이터 한계로 불가능 — 순증감(당월-전월)을 직접 프록시로 사용
7. **(추가, 2026-07-23)** 통계청 SGIS가 전국 격자(1km/500m/100m) 단위 유동인구를 제공해 유동인구 지방 커버리지 공백의 유력 후보로 확인됨. 반대로 상업용부동산 임대동향(한국부동산원 R-ONE)은 시군구 선택 자체가 불가능함을 확인 — 이 공백은 공공데이터로 해소 불가로 결론
8. **(추가, 2026-07-23)** LOCALDATA(지방행정인허가데이터) 포털은 2026-04-16 폐쇄, data.go.kr 업종별 표준데이터로 이관됨 확인 — sbiz 스냅샷의 "폐업일자 없음" 한계를 해결할 후보로 스키마 검증 필요(0절 참고)
9. **(추가, 2026-07-23)** sbiz 상가업소 274만 건 전수 점검 결과 같은 상호명+좌표 중복 등록 93,129건(3.4%) 발견·제거 — 좌표까지 다른 이종 중복(예: 쿠우쿠우동탄)은 자동 판단 불가로 잔존(1절 참고)
10. **(추가, 2026-07-24)** 리뷰 플랫폼(네이버플레이스/카카오맵) 데이터는 공식 대량조회 API가 없음(구글과 동일 구조) — 네이버는 크롤링 즉시 캡차 차단, 카카오는 공개 페이지 렌더링으로 실측 확보 가능함을 확인(9절 참고)

> - **localdata.go.kr 포털 자체가 2026-04-16 00:00부로 폐쇄됨**을 확인 — "지방행정인허가정보"와 "생활편의정보"는 이제 공공데이터포털(data.go.kr)의 **업종별 표준데이터**로 이관되어 제공됨(예: 전국일반음식점표준데이터, data.go.kr/data/15096283). 원래 팀 자료가 참고한 localdata.kr 주소는 더 이상 유효하지 않아 **data.go.kr 표준데이터 쪽으로 접근 경로를 수정해야 함**
> - 제공 방식: **파일 다운로드**(API 아님), 매일 갱신(2일 전 기준 현행화), CSV, 전국일반음식점만 213만 행
> - **⚠️ 실제 다운로드 시도 결과 — 파일 링크 자체가 죽어있음**: data.go.kr 페이지가 가리키는 다운로드 URL(`https://file.localdata.go.kr/file/general_restaurants/info`)이 302로 `/error.html`에 리다이렉트됨을 curl로 확인(2026-07-23). data.go.kr은 "기관자체 다운로드(제공데이터URL기재)" 방식이라 파일을 직접 호스팅하지 않고 옛 localdata.go.kr URL만 링크해뒀는데, 그 URL이 포털 폐쇄로 죽으면서 **data.go.kr 쪽 다운로드도 함께 끊긴 상태** — 행안부/식약처가 URL을 갱신할 때까지 이 경로로는 실제 CSV를 받을 수 없음
> - **✅ 컬럼 스키마는 확인됨(웨이백 머신 경유)**: data.go.kr 페이지·CSV 자체에서는 컬럼 목록을 못 찾았으나, 포털 폐쇄 전 LOCALDATA API 공식 문서(Wayback Machine 2025-10-25 스냅샷, `localdata.go.kr/devcenter/apiGuide.do`)에서 공통 응답 필드 전체를 확보. **`dcbYmd`(폐업일자), `clgStdt`/`clgEnddt`(휴업시작/종료일자), `ropnYmd`(재개업일자), `trdStateNm`/`dtlStateNm`(영업상태명/상세영업상태명), `apvPermYmd`(인허가일자), `x`/`y`(좌표정보)가 전부 존재**함을 원문 필드표로 확인. `state` 코드(01영업/02휴업/03폐업/04취소말소만료정지중지)까지 명시됨. 표준데이터(data.go.kr)는 이 LOCALDATA 소스 데이터를 그대로 표준화한 것이라 동일 필드가 CSV 헤더로 이어질 가능성이 매우 높음(단, 실제 CSV를 열어본 것은 아니므로 100% 확정은 아님)
> - **업종별로 데이터셋이 분리**됨(일반음식점/미용업/숙박업 등 개별 표준데이터) — 프랜차이즈 브랜드가 속한 업종에 맞는 표준데이터셋을 각각 찾아야 함, 통합된 단일 API 아님
> - **왜 중요한가**: sbiz 상가업소 데이터의 "스냅샷이라 폐업일자 없음" 한계(§21/§22, 좌표+상호명 퍼지매칭으로 근사 43.8%)를 정면으로 해결할 유력 후보 — 실제 폐업일자 필드가 존재하는 것으로 확인된 만큼, **다운로드 경로만 복구되면** 매장 단위 실측 개폐업 라벨을 직접 구성 가능. **다음 액션**: (1) data.go.kr 담당기관(식약처 043-719-2032) 문의 또는 대체 다운로드 경로 확인, (2) 다른 업종(치킨/커피/뷔페 등) 표준데이터도 동일 스키마인지 확인, (3) 실제 CSV 확보 시 헤더 재검증

## 9. 리뷰 플랫폼 데이터 (네이버플레이스/카카오맵) — 2026-07-24 조사 + 실측 검증

동료 팀(리뷰 감성분석 프로젝트)이 v2 피처로 제안 → 공식 API 존재 여부와 실제 확보 가능성을 직접 검증.

**공식 API 여부**
| 플랫폼 | 공식 대량조회 API | 비고 |
|---|---|---|
| 네이버플레이스 | 없음 | 개발자 커뮤니티에 "리뷰 데이터 연동(API) 제휴 문의" 글만 존재 — 개별 제휴 신청 외 경로 없음 |
| 카카오맵 | 없음 | 카카오 로컬 API(공식, 검색/좌표변환용)는 리뷰·평점 필드를 제공하지 않음 |

**법적 검토**: 대법원 2021도1533 판결(여기어때-야놀자) — 기술적 접근 제한 우회 없이 공개 페이지를 가져오는 것 자체는 형사책임 없음. 단, 대법원 2022도1533 판결은 같은 유형 사안에서 **데이터베이스제작자 권리 침해(민사)는 별개로 인정**됨을 확인 — 집계값(평점·리뷰수) 수준의 소규모 수집과, 리뷰 원문을 체계적·대량으로 저장하는 것은 리스크 등급이 다름.

**실측 결과(2026-07-24, 본죽&비빔밥 142개+쿠우쿠우 9개 매장 대상)**
- 네이버: 검색 API 첫 호출부터 `ncaptcha`(자동화 탐지) 응답 — 우회하지 않고 중단
- 카카오: 로컬 API(공식, 기존 `KAKAO_REST_API_KEY`)로 매장 매칭 + playwright로 공개 페이지 렌더링해 평점·리뷰수 추출 성공. 매칭률 본죽 93.0%/쿠우쿠우 66.7%. 단, 키워드 검색 API가 반경 내 매칭 실패 시 무관한 최근접 장소를 반환하는 함정 확인 — 브랜드명 토큰 포함 여부로 사후 검증 필요
- 리뷰수 분포(본죽 n=132): 중앙값 10, 10건 미만 49.2%, 20건 미만 86.4% — 소규모 매장 리뷰 수 신뢰성 우려가 실측으로 확인됨
- 평점·리뷰수와 실측폐업율(`clsbiz_rt`)/모델예측값 상관분석: 뚜렷한 유의미한 신호 없음(자세한 수치는 [[1. Projects/폐점 재계약 리스크 조기경보 모델]] 2026-07-24 로그 참고)

**결론**: 리뷰 데이터는 크롤링으로 소규모 실측은 가능하나, 공식 API 부재+네이버 차단+민사 리스크(대량 수집 시)를 감안하면 지금 표본 수준으로는 v2 정식 피처 채택 근거가 부족. 유동인구/경쟁밀도 통제 후 잔차 설명력 재검증이 선행 과제로 남음.
