# 데이터 소스 통합 인덱스

프로젝트별로 흩어져 있는 데이터 소스 조사 결과를 **출처(사이트/기관) 기준으로 재정렬**한 인덱스. 개별 데이터의 실사 확인 내용·API 스펙·제외 사유 등 상세 근거는 각 원본 문서를 참조할 것 — 이 노트는 복사가 아니라 "어디에 뭐가 있는지"를 빠르게 찾기 위한 지도.

## 요약 (핵심 3줄)
1. 3개 프로젝트가 각자 데이터를 조사하다 보니 **SGIS·서울 열린데이터광장·KOSIS 등 동일 소스가 여러 프로젝트에서 중복 확인**됨 — 신규 프로젝트 시작 시 이 문서를 먼저 확인하면 중복 조사 방지 가능
2. 서울 외 지역은 대부분 카테고리(유동인구·상권매출·임대동향)에서 **구조화 API 공백**이 반복적으로 발견됨 — "지방 커버리지 없음"은 프로젝트 개별 문제가 아니라 공공데이터 생태계 자체의 구조적 한계
3. data.go.kr은 사실상 여러 기관(국세청·공정위·한국부동산원·통계청 등)의 **API 게이트웨이 역할** — 기관 홈페이지보다 먼저 data.go.kr에서 검색하는 게 효율적

## 활용 방안
- 신규 프로젝트에서 지역 통계/상권/소상공인 데이터가 필요할 때 이 문서를 먼저 확인 → 이미 탈락한 소스 재조사 방지
- "서울 한정" 표시가 붙은 소스는 목표 지역이 비수도권으로 확정되는 시점에 재검토
- 각 소스의 실제 API 키·스펙·호출 예시는 원본 문서(위 링크) 또는 해당 프로젝트의 `docs/api_keys.md` 참고
