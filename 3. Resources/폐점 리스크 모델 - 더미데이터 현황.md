# 폐점 리스크 모델 — 더미데이터 현황

실제 데이터가 아직 연동되지 않아 화면·상담자료에 결정적(deterministic) 더미값을 채워 넣은
지점 전부를 한곳에 모은 목록. 전부 **매장 주소(또는 store_label)를 시드로 한
`hashlib.sha1`(백엔드)/동등한 JS 해시(`hashSeed()`, 프런트)** 방식이라, 같은 매장은 새로고침·
서버 재시작과 무관하게 항상 같은 값이 나온다(진짜 난수 아님) — Python 내장 `hash()`는
프로세스마다 솔트가 달라 재현이 안 돼 의도적으로 안 씀.

## 실제 데이터로 이미 대체된 것 (참고)

- **희망상권 후보지 임대 시세**: 한때 "완전 더미"였으나 2026-08-06~07 사이 국토교통부
  실거래가 API(`src/data/molit_client.py`)로 교체 완료 — 지금은 더미 아님.

## 알려진 갭 — 확인만 하고 아직 안 고침

- **`kimgane_risk_rankings.json`의 v1_percentile이 25개 매장 전부 11.8로 동일**(2026-08-11 발견):
  위 더미 오버라이드로 시연용 1건만 덮어썼을 뿐, 근본 원인(배치 스코어링 `batch_score_real_stores.py`
  또는 v1 분포 계산 쪽 버그로 추정)은 아직 안 고쳤음. 또한 이 파일 자체가 216개가 아니라
  25건뿐이라 — 216개 실매장 임포트 이후 배치가 재실행 안 된 것으로 보임. 재계산 필요.
- **전체 매장 목록의 평균 요약 사이드바(매출 평균/최고/최저 등)가 지금 안 보임**: 2026-08-07
  오전에 v1 `store-list.html`에 추가됐던 기능인데, 같은 날 오후 "클로드 스킬로 재기획한 v2를
  정식본으로 승격 + v1 삭제" 작업 때 v2 파일에는 이 기능이 원래 없어서 그대로 유실된 것으로
  보임(회귀). 재추가가 필요하면 알려주세요.
