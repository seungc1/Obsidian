## 요약 (핵심 3줄)
1. 분량·구조·시각자료 밀도는 수상작 수준에 근접(44슬라이드, 이미지 16장, 5부 구성+섹션전환+통계검증). **정책 시뮬레이션의 정량적 근거는 오히려 수상작 3편보다 강함**(정부 공식 산식·실측 지급률 기반 재계산 vs 수상작들의 정성적 활용방안).
2. **공간통계 검정(Moran's I/LISA)과 다중모델 비교(6개 ML 성능표 같은 것)가 없다는 게 가장 뚜렷한 격차** — 빈집ESG 대비 특히 두드러짐.
3. 44슬라이드는 수상작 3편(24/30/23) 중 가장 긴 편 — 제출 형식이 "PPT 요약"인 점을 고려하면 본편/부록 분리를 고려할 만함.

## 2. 방법론 깊이 비교 — 가장 중요한 격차

| 방법론 요소 | 열섬현상 | 빈집ESG | 소상공인 | **우리** |
|---|---|---|---|---|
| 다중 모델/기준 비교표 | ✅ AI 3종·회귀 3종·GWR 2종, R²/RMSE 정량비교 | ✅ 6개 ML/DL 모델(유형별), Hausman test로 공간모형 선택 | ✅ K-means Elbow, LQ+GAP 결정규칙 | ⚠️ 분류 임계값 후보비교표만 있음(모델 성능 비교 아님) |
| 가설검정(문제 존재 증명) | 없음(통계 인용만) | ✅ Welch t-test, Spearman, OLS 회귀표 | 없음 | ✅ Kruskal-Wallis, Mann-Whitney(실제 계산) |
| **공간 자기상관 검정** | GWR(지역별 계수 유의성)로 대체 | ✅ Moran's I, LISA(univariate/bivariate/dynamic), LOSH, Getis-Ord Gi* | 해당없음(상권 클러스터링) | ❌ **없음** — H-Lock은 가중합+Min-Max뿐 |
| 변수해석(SHAP 등) | 없음 | ✅ 유형별 SHAP 6세트 | 없음 | ✅ SHAP(1세트, 실데이터 검증) |
| 정책 효과의 정량적 시뮬레이션 | 정성적 서술(예산배분 등) | 정성적 서술(3단 카드) | 정성적+UI목업 | ✅ **정부 공식 산식·실측 지급률로 재계산**(가장 강함) |

**우리가 이미 이긴 지점**: 정책 제언 파트의 정량성. 세 수상작 모두 "정책 활용/기대효과"는 서술형 카드나 UI 목업으로 마무리하는데, 우리는 보건복지부 소득인정액 산식과 HF 실측 지급률로 "가입 전/후", "제도 vs 정책안" 수치를 직접 재계산했음. 이 부분은 굳이 더 보강할 필요 없음.

**우리가 진 지점**: 공간통계 검정. H-Lock Index 지도는 있지만 "인접 자치구끼리 값이 통계적으로 유사한가"(공간적 군집성)를 검정하지 않음 — 빈집ESG는 이걸 5가지 기법(Moran's I→LISA→Bivariate→Dynamic→Getis-Ord)으로 겹겹이 증명함. 시간이 더 있다면 Moran's I 하나만이라도 추가하면 격차가 크게 줄어듦(`libpysal`/`esda` 패키지로 반나절이면 가능).

## 3. 디자인·톤 비교

| 항목 | 수상작 공통 | 우리 |
|---|---|---|
| 컬러 시스템 | 브랜드 컬러 1~2개(남색/초록, 진남색/노랑 등) + 의미색(장점=파랑, 단점=빨강) 고정 | rust(위기)/brass(자산)/teal(공간·해결) 5부 컬러코드 + 의미색 별도 — **비슷한 성숙도** |
| 아이콘/일러스트 | 커스텀 라인아트·아이콘 세트(스카이라인, 학사모 등) | CSS 컴포넌트(배지·스테퍼·카드)뿐, 커스텀 일러스트 없음 |
| 실사 스크린샷/목업 | 소상공인: 실제 웹서비스 UI 스크린샷 1장 | 없음(HF 조회 화면 캡처는 자료로만 활용, 슬라이드엔 미포함) |
| 표지-클로징 수미상관 | 열섬·소상공인 모두 표지 요소를 클로징에 재사용 | 아직 대칭 구조 약함(감사인사만 별도 슬라이드) |

디자인은 "실제 디자이너가 만든 PPT" 수준의 커스텀 일러스트는 없지만, 데이터 시각화(차트·표·지도)의 완성도와 일관된 헤더/탭 시스템은 대등한 수준. 격차라기보다는 **제작 도구 차이**(우리는 HTML, 수상작은 실제 PPT 디자인 툴)에서 오는 자연스러운 차이.

## 4. 스토리라인 비교

세 수상작 공통 서사: 사회문제 통계 제시 → (선택)가설검정 → 자체 지수 정의·정당화 → 데이터/모델 비교 → 공간분석 심화 → 실제 지역 사례 검증 → 정책 활용(정성적) → 참고문헌.

우리 서사: 문제제기(집부자노인 역설) → 제도 한계 → 목적 → 데이터/분류체계/알고리즘 상세 → **통계검증(가설검정 위치가 살짝 늦음 — Part II 중반)** → SHAP → EDA1~9(+삶의질) → H-Lock(자체검증 포함) → 정책 4가지(정량 시뮬레이션).

**구조적 차이 하나**: 빈집ESG는 가설검정을 Part I(배경) 맨 앞에 배치해 "문제가 진짜 있다"를 제일 먼저 증명하고 시작하는데, 우리는 통계검증 슬라이드가 Part II(방법론) 중반부에 있어 다소 늦게 나옴. 순서상 큰 문제는 아니지만, 밀어붙이자면 슬라이드10a를 Part I 끝(슬라이드6 목적 다음)으로 옮기면 더 수상작 패턴에 가까워짐.

## 5. 종합 판단

- **내용의 엄밀성·투명성**(버그 발견·수정 기록, 근사치 한계 명시, 실측 데이터 기반 정책 재계산)은 수상작 대비 손색없거나 더 나음
- **공간통계 검정 부재**가 가장 눈에 띄는 격차 — 심사위원이 통계 전문가라면 이 지점을 물을 가능성 있음(Q&A 문서에 방어 논리는 있으나, 실제 검정 결과가 없다는 사실 자체는 못 채움)
- **분량 44슬라이드는 재검토 필요** — 상세 계산식 슬라이드(8a·10a·10d·17a·21a·22a) 7장을 부록으로 분리하거나, 발표시간 제약이 확인되면 그때 가서 쳐낼 후보로 미리 표시해두는 게 안전
