# 폐점·재계약 리스크 모델 — 개선 과제 목록 (2026-07-24 시점)

[[1. Projects/폐점 재계약 리스크 조기경보 모델]] v2 모델의 현재 한계를 정리한 목록. §22~§34까지의 실험으로 상당히 개선됐지만(Spearman 0.50→0.85), 아직 남은 문제를 우선순위별로 기록해 향후 작업의 기준으로 삼는다.

## A. 방법론 자체의 근본적 한계 (최우선)

1. **평가 방식이 엄밀한 홀드아웃이 아님** — ✅ **해결(2026-07-24)**. 대상 브랜드를 학습 데이터에서 완전히 제외하고 재평가한 결과, 정확 크로스워크 두 브랜드는 예상대로 하락(본죽 0.776→0.709, 명동칼국수 0.851→0.785)해 기존 수치가 다소 과장돼 있었음이 확인됐다. 다만 §22 시작점(0.50)과 비교하면 여전히 압도적으로 개선된 수준이라 **개선 방향 자체는 진짜**임이 검증됨. 쿠우쿠우는 오히려 상승(0.743→0.866)했는데 표본 9개의 소표본 노이즈로 판단. RMSE는 셋 다 홀드아웃에서 훨씬 나빠져(특히 쿠우쿠우 14.97), 신규 브랜드의 절대 점수 해석은 순위보다 신뢰도가 낮다는 것도 확인. 자세한 내용: `docs/design.md`의 "35"
2. **타겟이 매장 단위가 아니라 상권×업종 셀 단위 집계치** — `CLSBIZ_RT`는 같은 셀의 모든 매장이 공유하는 값. 진짜 매장 단위 생존/폐업 실측 라벨(§22, sbiz 스냅샷 diff)은 별도 분류 모델(브랜드 내부 AUC 0.54)로만 존재하고, 이 v2 회귀 모델의 학습 타겟과는 아직 통합되지 않음

## B. 데이터 커버리지·편향

3. **사실상 "한식 전용 모델"** — 학습 데이터의 77%가 한식(§34), 중식/일식/서양식은 유의미하지 않거나 매우 약함
4. **서울 지역 한정** — 구조화 API가 없어 다른 지역 확장 불가 확인됨(§29)
5. **표본이 작은 브랜드는 결론 불안정** — 쿠우쿠우(9개)처럼 피처 하나 추가할 때마다 수치가 흔들림

## C. 피처 관련 잔여 이슈

6. **매출 피처가 근사 매핑 브랜드엔 여전히 역효과**(§27-1) — 근본 원인(서울시 업종분류 10개뿐)은 해결이 아니라 회피(크로스워크 무관 피처 대체) 상태
7. **매출 결측 11%**(§27-3) — 소규모 상권 셀은 매출 정보 자체가 없음
8. **상권 배정이 근사치**(최근접 중심점, 실제 경계 아님)
9. **브랜드-매장 매칭이 상호명 부분일치 기반** — §34에서 `(주)식회사`류 오탐 실제 발견
10. **실제 매출은 시뮬레이션 단계**(§31) — 오버라이드 구조는 준비됐지만 실제 본사 데이터 없어 상한선 추정에 머묾

## D. 실사용 준비(엔지니어링) 격차

11. **v2용 배포 파이프라인이 없음** — v1은 `pipeline.py`로 신규 브랜드 입력→점수 산출이 되는데, v2는 학습/케이스 스터디 스크립트만 있고 실사용 인터페이스가 없음
12. **v1 매장 생존 분류 모델(AUC 0.54)과 v2 회귀 모델이 분리돼 있음** — 통합 방향 미정
