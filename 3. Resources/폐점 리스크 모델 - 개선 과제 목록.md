# 폐점·재계약 리스크 모델 — 개선 과제 목록 (2026-07-24 시점)

[[1. Projects/폐점 재계약 리스크 조기경보 모델]] v2 모델의 현재 한계를 정리한 목록. §22~§34까지의 실험으로 상당히 개선됐지만(Spearman 0.50→0.85), 아직 남은 문제를 우선순위별로 기록해 향후 작업의 기준으로 삼는다.

> **참고**: 아래는 2026-07-24 시점(HistGBR 기준) 기록이다. **2026-07-28 v2가 LightGBM으로 교체**되면서 성능 자체는 대폭 개선됐지만(자세한 내용 [[3. Resources/폐점 리스크 모델 - 케이스 스터디 종합]]), 아래 항목들이 다루는 피처/데이터/방법론 결정(업종 균형 가중치, 크로스워크 한계, 매출 결측 처리 등)은 알고리즘과 무관하게 여전히 유효하다.

## A. 방법론 자체의 근본적 한계 (최우선)

1. **평가 방식이 엄밀한 홀드아웃이 아님** — ✅ **해결(2026-07-24)**. 대상 브랜드를 학습 데이터에서 완전히 제외하고 재평가한 결과, 정확 크로스워크 두 브랜드는 예상대로 하락(본죽 0.776→0.709, 명동칼국수 0.851→0.785)해 기존 수치가 다소 과장돼 있었음이 확인됐다. 다만 §22 시작점(0.50)과 비교하면 여전히 압도적으로 개선된 수준이라 **개선 방향 자체는 진짜**임이 검증됨. 쿠우쿠우는 오히려 상승(0.743→0.866)했는데 표본 9개의 소표본 노이즈로 판단. RMSE는 셋 다 홀드아웃에서 훨씬 나빠져(특히 쿠우쿠우 14.97), 신규 브랜드의 절대 점수 해석은 순위보다 신뢰도가 낮다는 것도 확인. 자세한 내용: `docs/design.md`의 "35"
2. **타겟이 매장 단위가 아니라 상권×업종 셀 단위 집계치** — ✅ **부분 해결(2026-07-24)**. `CLSBIZ_RT`는 같은 셀의 모든 매장이 공유하는 값이라, v2에서 검증된 매장별 신호(상권변화/매출/유동인구/소비지출)가 셀 집계 타겟이 아니라 진짜 매장 단위 실측 생존 라벨(§22)에도 통하는지 교차 검증. 서울 부분집합(84개 브랜드) 기준 브랜드 내부 AUC가 0.5063→**0.5216**으로 개선돼 신호 자체의 유효성은 확인됐으나, 두 트랙(v1 분류 모델 vs v2 회귀 모델)을 하나로 합치는 완전한 통합은 서울 부분집합의 표본 부족(전국 모델 0.5411 대비 여전히 낮음)이 해소된 뒤로 미룸. 자세한 내용: `docs/design.md`의 "37"

## B. 데이터 커버리지·편향

3. **사실상 "한식 전용 모델"** — ✅ **해결(2026-07-24, 트레이드오프로)**. 업종 역빈도 가중치(power=0.5)를 기본값으로 채택 — 한식 성능이 다소 낮아지는 대신(본죽 0.776→0.605, 명동칼국수 0.851→0.736) 중식·일식·서양식 브랜드가 뚜렷이 개선됨(춘리마라탕 0.113→0.396로 처음 유의미). 순수한 개선이 아니라 "한식 특화"와 "여러 업종에 고르게 적용" 사이의 정책적 선택 — 자세한 내용: `docs/design.md`의 "39"
4. **서울 지역 한정** — 🔒 **구조적 한계, 조치 보류**. 경기도 등 유사 서비스는 구조화 API가 없어 자동화 불가함을 웹조사로 재확인(§29). 유일한 우회 후보였던 리뷰 데이터(팀원 제안)는 연관성 부족·현실적 제약(구조화 API 없음, 매장당 리뷰 수 부족)으로 최종 미채택 결정(2026-07-24, `docs/design.md` §40) — 서울 한정은 당분간 그대로 유지
5. **표본이 작은 브랜드는 결론 불안정** — ✅ **우회 해결(2026-07-24)**. 쿠우쿠우(9개) 단독 평가 대신, 같은 크로스워크 카테고리(구내식당·뷔페)의 다른 소규모 브랜드들과 풀링(166개 매장, 48개 브랜드)해 평가 — Spearman 0.646(p<0.0001)으로 훨씬 안정적이고 견고한 근거 확보. 개별 브랜드 표본 자체를 늘릴 수는 없지만, "묶어서 보는" 방법론으로 결론의 신뢰도는 확보 가능함을 확인. 자세한 내용: `docs/design.md`의 "42"

## C. 피처 관련 잔여 이슈

6. **매출 피처가 근사 매핑 브랜드엔 여전히 역효과**(§27-1) — ⚠️ **시도했으나 기각(2026-07-24)**. 근사 매핑 매장의 매출을 결측 처리하는 방안을 시도했으나 쿠우쿠우 Spearman이 오히려 0.717→0.498(유의성 상실)로 악화 — 부정확한 신호라도 없는 것보다는 낫다는 뜻으로 해석, 원상 복구. 근본 원인(서울시 업종분류 10개뿐)은 여전히 미해결. 자세한 내용: `docs/design.md`의 "38"
7. **매출 결측 11%**(§27-3) — ⚠️ **시도했으나 기각(2026-07-24)**. 업종별 중앙값으로 대체(imputation)하는 방안을 시도했으나 쿠우쿠우 Spearman이 0.743→0.516(유의성 상실)로 악화 — 결측 자체가 매장 간 차이의 일부였는데 획일적 대체값이 그 차이를 지워버린 것으로 판단, 원상 복구. HistGradientBoostingRegressor의 결측 자체 처리에 맡기는 게 imputation보다 낫다는 걸 C-6과 함께 두 번째로 확인. 자세한 내용: `docs/design.md`의 "41"
8. **상권 배정이 근사치**(최근접 중심점, 실제 경계 아님) — 🔒 **구조적 한계, 조치 보류**. 서울 열린데이터광장이 상권 경계 폴리곤을 제공하지 않아(중심좌표+면적만) 해결 불가 — 상권 경계 데이터가 별도로 공개되면 재검토
9. **브랜드-매장 매칭이 상호명 부분일치 기반** — ✅ **점검 완료, 코드 수정은 보류(2026-07-24)**. `(주)식회사`류 오탐(§34)의 원인은 매칭 알고리즘 버그가 아니라 FTC 원본 데이터 자체의 브랜드명 필드가 일부 브랜드에서 회사명 접미사만 남아있는 데이터 품질 문제로 확인 — 정식 브랜드명 필드를 재파싱하는 근본 수정은 공수가 커서, 지금은 케이스 스터디 브랜드 선정 시 수작업으로 걸러내는 방식(§34에서 이미 적용) 유지
10. **실제 매출은 시뮬레이션 단계**(§31) — 🔒 **외부 의존, 조치 보류**. 오버라이드 구조(§31 후속)는 준비 완료 — 본사 실제 매출 데이터가 확보되면 즉시 반영 가능, 지금은 대기 상태

## D. 실사용 준비(엔지니어링) 격차

11. **v2용 배포 파이프라인이 없음** — ✅ **해결(2026-07-24)**. `src/pipeline_seoul.py` 신설 — 신규 매장 주소+업종(+브랜드명)을 넣으면 학습 때와 동일한 데이터 결합 체인을 거쳐 위험 점수를 산출. 구현 중 경쟁밀도 카테고리 해상도 불일치(소분류 필요, v2는 중분류만 다룸 → 최빈 소분류로 근사)와 저장된 모델 파일이 §33 실험 시점 것으로 코드와 어긋나 있던 문제(재학습으로 해결)를 발견·수정. 명동 실주소로 동작 확인 완료. 자세한 내용: `docs/design.md`의 "36"
12. **v1 매장 생존 분류 모델(AUC 0.54)과 v2 회귀 모델이 분리돼 있음** — ✅ **신호 차원 통합 성공(2026-07-24)**. v1(전국, FTC 기반)의 최강 신호였던 업종 피어평균 해지율을 v2에 이식 — 본죽 0.605→0.649, 명동칼국수 0.736→0.748로 개선, 쿠우쿠우는 변화 없음(악화 없음). 지금까지 시도한 어떤 피처 추가보다 안전한(모든 브랜드 개선 또는 무변화) 결과. 다만 두 모델을 하나의 파이프라인·하나의 출력으로 합치는 완전한 통합은 서울 부분집합 표본 부족(§37)이 해소된 뒤로 계속 미룸. 자세한 내용: `docs/design.md`의 "43"

### 2026-07-24 (계속) — D-11(v2 배포 파이프라인) 완료

### 2026-07-24 (계속) — A-2(매장 단위 타겟과 v2 신호 교차 검증) 부분 완료
서울 부분집합에서 v2 매장별 신호가 진짜 실측 생존 라벨에도 유효함을 확인(위 항목 참고).
완전한 단일 모델 통합은 표본 크기 문제가 남아 후속 과제로 보류.

### 2026-07-24 (계속) — 나머지 항목 전수 정리, 12개 항목 전부 상태 확정
C-6(매출 결측 처리)을 시도했으나 쿠우쿠우 성능이 악화돼 기각(§38). B-3(한식 편중)은
업종 균형 가중치 도입으로 해결하되 트레이드오프임을 명시(§39) — 이 변경으로 본죽/명동칼국수
벤치마크가 재조정돼 관련 vault 문서(모델 정의서 v2, 케이스 스터디 종합, 개별 케이스 스터디
노트)를 전부 새 기준으로 갱신. 나머지(B-4/5, C-7/8/10, D-12)는 코드로 해결 불가능한
구조적 한계 또는 외부 의존으로 판단해 "조치 보류"로 명시적으로 닫음 — 이제 12개 항목
전부 상태가 확정됨(해결 5, 트레이드오프로 해결 1, 시도 후 기각 1, 구조적 한계로 보류 5).

### 2026-07-24 (계속) — "조치 보류" 항목 중 3개 재시도, 전부 상태 갱신
B-5/C-7/D-12는 "구조적 한계"로 분류했지만 완전히 손 놓을 필요는 없다고 판단해 재시도.
**C-7**: 매출 결측을 업종별 중앙값으로 대체 시도 → C-6과 같은 이유로 쿠우쿠우 악화(기각,
§41). **B-5**: 쿠우쿠우 단독 대신 같은 크로스워크 카테고리 전체를 풀링해 평가 →
Spearman 0.646(n=166, p<0.0001)의 훨씬 견고한 근거 확보로 우회 해결(§42). **D-12**:
v1의 업종 피어평균 해지율을 v2에 이식 → 본죽 0.605→0.649, 명동칼국수 0.736→0.748로
개선, 쿠우쿠우 변화 없음 — **지금까지 시도한 어떤 피처 추가보다 안전한(전부 개선 또는
무변화) 첫 사례**(§43). v2 정식 벤치마크가 다시 한번 갱신됨.
