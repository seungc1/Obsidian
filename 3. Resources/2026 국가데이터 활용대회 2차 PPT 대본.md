**변환 과정에서 발견·수정한 실제 CSS 버그 3건** (HTML 원본에도 반영 완료):
1. 스크롤 진입 시 페이드인되는 애니메이션 때문에, 헤드리스 캡처 시 화면 밖에 있던 슬라이드가 전부 빈 화면으로 캡처됨 → `prefers-reduced-motion` 방식으로 우회

> 말킥: 창신동 사건은 담담하게, 통계 뒤에 실제 비극이 있다는 톤으로. 27.3%→0.0%라는 숫자 낙차를 강조.

```
H-Lock Index = 0.35×주거고착지수 + 0.30×소득취약지수
```
