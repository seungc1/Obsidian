## 요약 (핵심 3줄)
1. 세 작품 모두 "단순 현황 통계 → 자체 정의한 복합지수/모델 → 통계적 검증 → 실제 지역 사례 검증 → 구체적 정책 제언"의 5단계 서사를 공통으로 따름
2. 여러 방법론(모델/지표)을 나란히 비교해 정량적으로 최적을 골랐다는 점을 명시하는 것이 세 작품 모두의 핵심 설득 장치
3. 분석 결과를 실제 행정동 1~2곳 사례로 좁혀 "우리 결과가 실제로 말이 되는지" 검증하는 단계가 반드시 있음

## 1. 서울특별시 열섬현상 (행정동별 원인 분석 및 맞춤형 완화 방안)

- **자체 지표 정의**: 기존 "온도"가 아니라 `UHII = 해당 행정동 온도 - 주변(2~10km) 지역 평균 온도`라는 지수를 직접 정의하고 수식·의미를 명시
- **방법론 비교표**: 인공지능(MLP/CNN) vs 회귀분석(OLS Full/Stepwise/Heuristic) vs 공간통계(GWR Full/Selected) 6개 모형을 R², Adj_R², RMSE, MAE 4개 지표로 나란히 비교 → GWR Full이 최고(R²=96.1%)임을 표로 증명
- **공간가중회귀(GWR)**: 행정동마다 회귀계수가 다르다는 점을 활용 — "같은 변수라도 지역마다 영향 방향이 다르다"를 보여줌(예: 성남시 인접지역은 철도 비율↑→열섬 심화, 녹지 비율↑→완화, 유의수준 0.05 명시)
- **정책 직결**: 분석에서 나온 지역별 유의 변수를 그대로 정책 수단에 매핑(도로 영향 큰 지역 → 쿨페이브먼트, 철도 인접 → 바람길 조성)
- **약점 없는 구성**: 목차 4단계(배경/방법론/결과해석/정책활용)가 그대로 슬라이드 섹션 구분과 일치, 참고문헌 5편 명시

## 2. 빈집 발생의 다차원적 진단과 관리 전략 (ESG 중심)

가장 방법론이 두꺼운 작품. 잘된 점이 많음:

- **가설검정으로 문제를 먼저 증명**: 본론 모델링 전에 "수도권과 지방 빈집률이 통계적으로 다른가"(Welch's t-test), "빈집비율과 지역소멸위험지수가 상관있는가"(Spearman -0.707, 회귀 R²=0.449)를 먼저 검정 → 왜 이 분석이 필요한지 통계로 정당화
- **통계 신뢰성 문제 자체를 소재화**: "통계청 공식 빈집 통계가 지자체 실태조사와 16배 차이난다"는 실제 뉴스 팩트를 배경 슬라이드에 배치해 데이터 품질 문제 자체를 연구 동기로 활용
- **데이터 총량 과시**: 8개 카테고리(주택/환경/사회/거버넌스/인구/인프라/안전/교통/경제), 50개 데이터셋, 405개(파생변수 포함) 변수 — 출처 표에 전부 KOSIS/MDIS/공공데이터포털/부동산통계정보로 명시
- **깊은 공간통계 스위트**: Moran's I(전역 자기상관) → LISA(국지적 클러스터, High-High/Low-Low 등 4분면 해석) → Bivariate LISA(빈집×고령화 두 변수 교차) → Dynamic LISA(2019→2023년 클러스터 전이, Rayleigh 검정까지) → LOSH/Getis-Ord Gi*(이상값·핫스팟) → 공간패널회귀(Robust LM Error/Lag test, Hausman test로 모형 선택 근거 제시, 최종 Panel FE-Lag 채택)
- **6개 ML/DL 모델을 유형별로 각각 비교**: 빈집을 합계+5개 주택유형(단독/아파트/다세대/연립/비주거)으로 나눠 XGBoost/LightGBM/CatBoost/RandomForest/Ridge/LSTM을 각각 R²로 비교해 유형마다 최적 모델이 다름을 보여줌(단독주택은 LightGBM, 연립은 CatBoost 등)
- **SHAP을 유형별로 전부 따로 해석**: 6개 주택유형마다 SHAP 변수중요도 그래프+주요 영향변수 3~5개를 "왜 그런지" 한 줄 해석과 함께 제시(예: "단독주택은 에너지효율성 낮을수록 빈집 증가—난방비 부담")
- **지수의 장단점을 스스로 비교**: "빈집비율(단순)" vs "빈집지수(ESG 종합, MixedLM 기반)"를 장단점 표로 나란히 제시해 왜 새 지수가 필요한지 설득
- **혼합효과모형(MixedLM)으로 지역 이질성 처리**: 시도별 랜덤효과를 명시적으로 추정해 "시도마다 다른 ESG 가중치"를 산출(예: 제주·충남·전북은 환경 요인이, 서울·경북은 사회 요인이 지배적)
- **지역 사례 검증**: 대구 수성구(재건축으로 경제요인 변동성 큼) vs 경남 합천군(고령화·경제정체로 빈집지수 상승 추세)을 대비시켜 지수가 실제로 말이 되는 스토리를 보여줌
- **활용 방안의 실물화**: 리포트에서 그치지 않고 Gemini 기반 챗봇 웹앱(QR코드 포함, Role-Playing/Persona/Few-shot 프롬프트 엔지니어링 명시)까지 제작해 "정책 제언"을 실제 서비스로 확장

## 3. 소상공인 생존을 높이는 데이터 전략 (소비자 성향 기반 상권 분석)

- **연구 요약 슬라이드를 목차 직후에 배치**: "무엇을 했고 무엇을 만들었는지"를 2문장으로 먼저 요약, 이후 상세 전개
- **기존 공공서비스의 한계를 명시적으로 짚고 시작**: "기존 상권분석 서비스는 공급자 중심 지표(점포수·매출)에만 의존하고 수요 기반 정보가 부족하다"를 문제로 제시 → 자신들의 "수요-공급 매칭" 접근과 대비
- **3단계 전략을 로드맵 다이어그램으로 먼저 제시**: 1단계 상권 클러스터링 → 2단계 수요-공급 요인 분석(LQ+GAP, 관심도점수) → 3단계 업종·입지 추천, 이후 슬라이드가 정확히 이 순서를 따름
- **K-means 군집 수를 Elbow 기법으로 정당화**하고(서울 K=7, 경기 K=8), 각 클러스터에 "교육·유통 복합 상권", "외식 중심 청년층 상권" 같은 사업적 의미가 통하는 이름을 붙임(단순 Cluster 1/2/3이 아님)
- **각 클러스터를 실제 행정동 예시로 구체화**(예: "외식 중심 청년형 = 연남·이태원2·합정동")해 추상적 통계를 즉시 체감 가능하게 만듦
- **입지계수(LQ)+GAP분석 병행**: LQ<1 & GAP<0(지역 특화도는 낮지만 수요 대비 공급 부족)인 업종을 "유망 업종"으로 정의하는 명확한 의사결정 규칙 제시, 각 지표에 해외 학술 출처(BEA, Barta&Woods) 인용
- **자체 종합점수도 공식화**: 평균소비금액·건당평균금액·평균이용건수·소비강도 4개 지표를 Min-Max 정규화(25%씩 가중) 후 Z-score로 고유망/중상/중하/저유망 4단계 분류
- **분석 결과를 실측치로 검증(타당성 검증 슬라이드)**: 추천된 양재2동·사직동의 "서울 신생 외식업 생존율 추이"를 서울시/자치구 평균과 비교해 실제로 생존율이 높다는 걸 별도 데이터로 재확인 — "우리 모델이 추천한 곳이 실제로도 안전한 상권인가"를 검증한 것이 핵심
- **서비스 예시(대시보드 mockup)로 마무리**: 소상공인이 실제로 볼 화면을 시각화해 활용 방안을 구체화

## 공통 패턴 (세 작품 종합)

1. **문제를 통계로 먼저 증명한다**: 본격 분석 전에 가설검정(t-test/Kruskal-Wallis)이나 격차 수치(3.7배, 16배 등)로 "이 문제가 실재하고 심각하다"를 데이터로 증명
2. **기존 통계/서비스의 한계를 명시적으로 비판**하고 자기 지수/모델이 그 한계를 어떻게 극복하는지 대비시킴 (빈집비율 vs 빈집지수, 기존 상권서비스 vs 수요기반 프레임워크)
3. **자체 정의 지수·점수에는 반드시 수식을 명시**하고, 그 지수가 왜 타당한지 통계적 근거(가중치 산출 방법, 정규화 방식)를 설명
4. **여러 모델/방법론을 나란히 비교하는 표**를 반드시 넣음 — 단일 모델을 쓰더라도 "왜 이걸 선택했는지"를 다른 대안과의 정량 비교로 증명(회귀/GWR 6종 비교, ML 6종 비교, 인덱스 2종 비교)
5. **모델 해석가능성(SHAP)을 정책 언어로 번역**: SHAP 값 자체가 아니라 "X가 낮을수록 Y가 증가한다 → 그러므로 정책 Z" 한 문장으로 항상 마무리
6. **공간 단위 세분화**: 시도/전국 평균에 머물지 않고 행정동·시군구 단위로 내려가 지역 이질성을 직접 보여줌(GWR 지역별 계수, LISA 클러스터, 시도별 랜덤효과, K-means 클러스터의 실제 행정동)
7. **실제 사례 1~2개로 마무리 검증**: 분석 결과를 임의의 한두 지역에 적용해 "말이 되는 서사"로 풀어내는 슬라이드가 반드시 있음(성남 인접지역, 대구 수성구/경남 합천군, 양재2동/사직동)
8. **정책 제언이 분석 결과와 1:1로 연결**됨 — "이 변수가 유의하다 → 그러므로 이 정책"이 표/문장으로 직접 이어짐
9. **여력이 되면 산출물을 서비스로 확장**(챗봇 웹앱, 대시보드 mockup)해 "제안"이 아니라 "당장 쓸 수 있는 것"임을 보여줌
10. **일관된 슬라이드 구조**: 표지 → 목차 → 배경/문제제기 → 데이터/방법론 → 분석결과 → 정책활용 → 참고문헌 → 감사인사. 각 섹션 상단에 현재 위치를 표시하는 헤더바(예: "02 데이터 분석")를 유지

## 우리 프로젝트 대비 시사점

[[1. Projects/2026 국가데이터 활용대회 - 고령층 자산정책 2차심사 준비]]의 1차 보고서와 비교하면:

- **이미 갖춘 것**: 자체 정의 지수(취약지수 = 가중합), 3중 교차검증 유형분류(A/B/C/D), SHAP 변수중요도([그림3], 담당 팀원 B), 지역 사례 검증(강북구·금천구 등 취약지수 상위 5개구), 정책 제언과 시뮬레이션 결과 직결(제언1~4 각각 가입 전/후 수치)
- **보강하면 좋을 부분**:
  - 여러 방법론/모델을 나란히 비교하는 표가 없음(수상작들은 전부 "모델 A vs B vs C" 비교표로 선택 근거를 증명) — 취약지수 가중치(0.35/0.30/0.25/0.10)나 3중 교차검증 임계값(소득분위 2, 자산분위 4)이 왜 그 값인지 통계적 근거를 보강하면 설득력이 커짐
  - 가설검정(t-test, Kruskal-Wallis 등)으로 "B유형이 통계적으로 별도 집단"임을 증명하는 단계가 없음 — 소득/자산 분포가 A/B/C/D 유형 간 유의하게 다른지 검정 결과를 넣으면 좋음
  - 공간분석에 Moran's I/LISA 같은 공간 자기상관 검정이 없음(자치구 취약지수 지도는 있지만 "인접 자치구끼리 값이 실제로 유사한가"를 통계로 증명하지 않음) — 팀원 C 담당 부분과 연계 시 고려
  - 서비스화(챗봇/대시보드) 요소는 없음 — 시간 여유가 있다면 2차 PPT에 "향후 확장" 슬라이드로 웹앱/대시보드 컨셉만이라도 제시하면 가산점 여지
