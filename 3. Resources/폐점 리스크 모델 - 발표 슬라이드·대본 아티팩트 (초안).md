## 디자인 시스템

**UI/UX Pro Max 스킬**의 `slides` 컴포넌트 + `design-system` 컬러 DB를 적용한 **다크 대시보드 팔레트**("Financial Dashboard" 계열)로 확정:
- 배경 `#020617`, 카드 `#0E1223`, 포인트 컬러 그린 `#22C55E`(최종 선정·긍정 지표), 레드 `#EF4444`(고위험 등 상태 표시 전용)
- **풀스크린 1장씩 넘기는 프레젠테이션 셸** — 방향키/스페이스바/클릭/하단 버튼으로 이동, 진행바·슬라이드 카운터 포함
- 차트는 Chart.js(CDN 차단) 대신 **자체 제작 SVG**(hover 툴팁, 오차막대, 애니메이션 진입 효과 포함)
- 상태 요소(최종 선정·고위험)는 색상+텍스트 라벨+아이콘(체크서클·경고삼각형 SVG) 3중 인코딩

## 구성 (20장, 5개 막)

1. **문제**(01~02): 표지 · 문제 정의
2. **데이터와 방법**(03~07): 분석 로드맵(전체 흐름 요약) · 데이터셋 9종 · 데이터 처리 6단계(수집·매칭·정제·타겟라벨·피처·파이프라인) · 전국→서울 전환점 · 모델 구조
3. **모델이 증명하는 것**(08~09, 11): 알고리즘 8종 비교 · 운영 흐름(전처리→예측→SHAP→매트릭스→조항) · 튜닝·20시드 검증
4. **무엇이 위험을 만드는가**(10, 12~13): 결과 활용처(역할별+운영루프) · SHAP 위험요인 · 47브랜드 교차검증
5. **결과의 활용**(14~20): 성능 여정 · 위험 매트릭스 · 조항 가이드 · 케이스 스터디 · 로드맵(Phase 1~3) · 한계 · 마무리

## 상태 (작업 이력)

- **2026-08-12**: 초안 v0.1(15장, v1·v2 병기, 스톤 팔레트).
- **2026-08-13~14 1차 재구성**: 서울 중심 v2 단일 모델로 전면 재구성(21장) — v1 개별 설명 제거, 전국→서울 서사를 1장으로 압축.
- **저장소 실측 반영**: 코드 저장소(`closure-risk-model`) `docs/figures/`의 실제 차트 이미지에서 8개 알고리즘 1차 비교 전체 수치, SHAP 상위 8개 정확값, 20시드 검증, 데이터 계층 구조, 5개 브랜드 알고리즘 교체 전후 실측값을 확인해 반영(지어낸 수치 없음).
- **이전 기수 발표자료 10편 조사 반영**: 베이스라인→최종 모델 전환 문장 + 트레이드오프 표, "최종 모델 선정" 배지, SHAP 3열 표(요인·방향·의미), human-in-the-loop 문구. 10개 팀 중 SHAP 시각화 팀 없음을 확인(차별점).
- **UI/UX Pro Max 스킬 적용 · 전면 개편**: 스톤 팔레트를 폐기하고 다크 대시보드 팔레트로 전환, 풀스크린 네비게이션 셸 도입, 콘텐츠를 처음부터 재구성(21장 → 16장으로 압축, 슬라이드 그룹 통합).
- **출처·설명 보강**: 사용자 피드백("출처 표기 필요", "내용이 너무 빠짐") 반영 — 전 슬라이드 하단에 데이터/코드 출처 표기, 데이터셋·SHAP·매트릭스·한계 등 압축됐던 설명 문장 복원.
- **키워드·문장 밀도 강화**: 핵심 용어 칩·볼드 강조 추가(16장 유지).
- **"분석 로드맵" 슬라이드 신설**(팀 참고 이미지 기반): 데이터 수집→분석 과정→결과를 한 장으로 요약(17장).
- **"데이터 처리 과정" 슬라이드 신설**: 수집·매칭·정제·타겟라벨·피처·파이프라인 6단계를 완전한 문장으로 상세 설명(18장).
- **"전문 기법 흐름" 슬라이드 신설 → 재정의**: 처음엔 8개 알고리즘 비교를 포함한 "기법 용어 정리"로 만들었으나(19장), 사용자 피드백("모델 선택 이유가 아니라 완성된 모델의 동작 흐름을 보여줘야 함")에 따라 **알고리즘 비교 내용을 전부 제거**하고 순수 운영 흐름(전처리된 피처→LightGBM 추론→SHAP→백분위 변환→2×2 매트릭스→조항 매핑)으로 재작성.
- **"결과는 어디에 쓰이는가" 슬라이드 신설**(20장, 현재): 역할별 활용표(담당자/법무팀/경영진/데이터팀) + 6단계 운영 루프 + Phase 1 현재 상태 표시.
- **매칭·정제 단계 표현 압축**: 문단형 설명을 "269배→216개", "버그 1개→지표 4개↑" 같은 큰 숫자+태그 형태로 재작성해 임팩트 강화.
