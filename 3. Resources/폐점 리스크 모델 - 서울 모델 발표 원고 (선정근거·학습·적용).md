## 서울 모델 — 선정 근거

- 8개 알고리즘(HistGBR·LightGBM·XGBoost·CatBoost·RandomForest·GradientBoosting·ExtraTrees·Ridge) 동일 조건 비교, LightGBM 우위 확인(Spearman 0.553 vs 0.545)
- 하이퍼파라미터 20회 랜덤서치로 최적화(Spearman 0.731, RandomForest 근접 2위 0.725)
- 20개 시드 반복 검증(분할 자체도 매 시드 재생성): 20회 전원 우위, 통계적 유의성 확보(p<0.0001)
- 순위상관 20시드 평균 0.518→0.718, RMSE 평균 6.22→5.55로 개선, LightGBM 정식 채택(HistGBR 대체)
- 47개 브랜드 확대 재검증: 순위상관 범위 0.11~0.91 → 0.59~0.98로 대폭 개선(상위 10개 전부 한식)

## 서울 모델 — 학습 방식

- 타겟: 서울 열린데이터광장 실측 폐업율(상권×업종×분기, `CLSBIZ_RT`) 직접 적용, 역산 없이 사용
- 브랜드 공통 변수: 계약기간·초기비용·업종·업종 피어평균 해지율(전국 모델 v1에서 산출된 값 이식)
- 매장별 변수: 경쟁밀도(250m/500m)·배후인구·상권변화지표·추정매출·유동인구(점심/저녁)·행정동 소비지출·지하철역 거리
- 매장→상권 배정: 최근접 상권 중심점 배정(근사, 경계 폴리곤 데이터 부재)
- 무작위 분할(80/20, 매장 단위), 표본크기 가중 × 업종 균형 보정 가중치 반영
- SHAP(Permutation Explainer) 기반 피처 기여도 산출
- 핵심 원칙: 업종 크로스워크 의존도가 낮은 변수(유동인구·상권변화지표 등)일수록 근사매핑 브랜드에도 안전하게 범용 적용

## 서울 모델 — 적용 방식

- 매장 주소·업종(+브랜드명) 입력 → 매장별 상대 위험 순위 산출(`src.pipeline_seoul`)
- 전국 모델과 결합해 백분위 기준 2×2 매트릭스 분류(`src.combine_scores`): 고위험 / 업종위험 / 입지위험 / 안전
- SHAP 기반 위험요인 순위 → 예방조치·재계약 조항 후보 자동 생성(`src.clause_recommendation`), 방향성 자동 검증 및 이상 신호 경고 표시, 법무 검토용 초안으로 활용(최종 결정은 담당자)
- 단계별 롤아웃: 파일럿(김가네, 서울 88개 매장 포함 전국 216개 실매장) 시범 적용 → 전 브랜드 확대 및 조항 추천 법무 검토용 시범 도입 → 담당자 화면 정식 반영 및 피드백 기반 고도화
