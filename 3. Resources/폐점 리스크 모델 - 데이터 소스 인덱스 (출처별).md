# 폐점 리스크 모델 — 데이터 소스 인덱스 (출처별)

[[3. Resources/데이터 소스 통합 인덱스]]에서 [[1. Projects/폐점 재계약 리스크 조기경보 모델]] 관련 항목만 분리한 버전. API 스펙·실사 검증 근거·수치 등 상세 내용은 [[3. Resources/폐점 리스크 모델 - 공공데이터 소스 목록]](카테고리별 원본)을 참조 — 이 노트는 "어느 사이트에 뭐가 있는지"를 빠르게 훑기 위한 요약.

## 요약 (핵심 3줄)
1. 핵심 채택 소스는 **data.go.kr(개폐업/사업자현황/가맹정보) + 서울 열린데이터광장(유동인구/매출/소득소비) + KOSIS·SGIS(인구/기업생멸/임대)** 3축으로 구성
2. 서울 열린데이터광장 소스가 v2 모델 정확도 개선의 대부분을 차지 — 특히 유동인구·소득소비는 업종 크로스워크가 필요 없어 근사 매핑 브랜드에도 안전
3. 리뷰 플랫폼(네이버/카카오)·한국부동산원 R-ONE 시군구 임대료는 확인 결과 실사용 불가로 결론난 소스 — 재조사 불필요

## 1. 공공데이터포털 (data.go.kr)

| 데이터셋                               | 상태                               |
| ---------------------------------- | -------------------------------- |
| 소상공인시장진흥공단 상가(상권)정보 Open API/파일데이터 | 채택 — 개폐업 diff 라벨링                |
| 국세청 사업자현황 100대 생활업종                | 채택 — 순증감 프록시(A 소스)               |
| 공정위 가맹정보(정보공개서 목록/목차/본문, 업종개황)     | 채택 — 크롤링 불필요 확인                  |
| 한국부동산원 상업용부동산 임대동향/공실률             | 부분 채택 — 시군구 선택 불가로 실사용은 KOSIS 경유 |
| 전국일반음식점표준데이터(구 LOCALDATA 이관)       | 보류 — 다운로드 링크 죽음(2026-07-23)      |
| KOSIS 지표정보 조회 API(프록시)             | 채택                               |
| 서울교통공사 지하철역 좌표(odcloud)            | 채택 — 지하철거리 피처                    |

## 2. 서울 열린데이터광장 (data.seoul.go.kr)

서울 한정. "사람이 보는 웹(golmok.seoul.go.kr)"과 "기계가 호출하는 구조화 API"가 이중으로 존재하는 유일한 지자체.

| 데이터셋                        | 상태                        |
| --------------------------- | ------------------------- |
| 상권분석서비스 — 상권영역              | 채택                        |
| 상권분석서비스 — 길단위인구(유동인구, 시간대별) | 채택 — 업종 크로스워크 불필요, 개선폭 최대 |
| 상권분석서비스 — 추정매출(상권x업종)       | 채택 — 크로스워크 정확도에 성패 좌우됨    |
| 상권분석서비스 — 상권변화지표            | 채택                        |
| 상권분석서비스 — 소득소비(행정동)         | 채택                        |

## 7. 제외/보류 (재조사 방지용)

| 소스 | 사유 |
|---|---|
| 네이버플레이스 리뷰 | 공식 API 없음, 크롤링 즉시 캡차 차단 |

| LOCALDATA(지방행정인허가데이터) | 포털 폐쇄(2026-04-16), data.go.kr 이관처 다운로드 링크도 죽음 |
