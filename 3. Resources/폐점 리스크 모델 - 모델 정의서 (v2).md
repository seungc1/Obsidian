# 모델 정의서 (v2) — 서울 한정 프랜차이즈 매장 단위 폐업 리스크 모델

## 1. 모델 설명

- 목표: 동일 브랜드 내 매장 간 상대적 폐업 위험 구분(서울 지역 한정)
- 타겟: 매장이 속한 상권×업종의 실측 분기별 폐업률(공개 통계 직접 활용) — 매장 좌표로 최근접 상권 배정, 업종은 해당 통계 분류체계로 매핑
- 입력 데이터: 브랜드 공통 정보 + 매장별 신호(경쟁점포 밀도, 배후인구, 상권변화지표, 추정매출, 유동인구 총량/점심/저녁, 행정동 소비지출 총액/음식지출액)
- 실 배포 대비: 매출 피처는 본사가 보유한 실제 가맹점별 매출값이 있으면 그 값을 우선 사용하고, 없는 매장만 공공데이터 근사치로 채우는 구조로 설계(현재는 실제 값이 없어 사실상 항상 근사치 사용)
- 모델: 그래디언트 부스팅 회귀 알고리즘, 상권 표본 크기 기반 가중치 적용
- 평가 방식: 특정 브랜드의 매장 표본에 적용해 예측-실측 순위상관으로 검증

## 2. 초기 결과 및 평가

- 매장별로 다른 값을 갖는 신호 추가가 브랜드 내부 구분력을 실제로 높이는지 사전 검증
- 브랜드 공통 정보만 사용 시 브랜드 내부 구분력 수학적으로 무의미(완전 무작위 수준) → 경쟁밀도·배후인구 추가로 구분력 개선 확인
- 최초 회귀모델을 소규모 브랜드(매장 9곳)에 적용 → 예측오차는 베이스라인과 유사, 배후인구가 최상위 신호
- 실측 폐업률 편차(0~50%) 대비 예측범위는 매우 좁게 몰림(과소적합)
- 원인: 표본 부족 + 업종 매핑 근사 → 대형·정확매핑 브랜드로 검증 전환 필요

## 3. 모델 최적화 진행 사항

- 대형·정확 업종매핑 브랜드(매장 142곳)로 전환 → 예측범위 확대
- 상권변화지표 추가 → 순위상관 통계적 유의수준 확보
- 데이터 정제(중복 등록·매장 식별 오류 수정) → 전 지표 개선
- 추정매출 피처 추가 → 지금까지 최대 개선폭, 단 근사매핑 브랜드에는 오히려 역효과 확인
- 소규모 상권에서는 매출 데이터가 구조적으로 결측되는 패턴 확인
- 업종 매핑에 의존하지 않는 유동인구 추가 → 두 브랜드 모두 개선, 시간대(점심/저녁) 세분화로 추가 개선
- 시사점: 업종 매핑에 의존하지 않는 신호일수록 여러 브랜드에 범용적으로 적용 가능
- 두 번째 대형·정확매핑 브랜드(매장 90곳)로 같은 피처셋 재현 → 유사한 수준의 순위상관 확인, 개선이 특정 브랜드에 국한된 우연이 아님을 검증
- 업종 매핑에 의존하지 않는 행정동 단위 소비지출 정보 추가 → 대형·정확매핑 두 브랜드 모두 추가 개선
- 학습에 쓰인 매장을 평가에도 포함하는 방식(누수 있는 평가)이었음을 확인 — 대상 브랜드를 학습에서 완전히 제외한 뒤 재평가하니 수치가 다소 낮아짐(부풀려짐 확인), 다만 개선 방향 자체는 유지됨
- 학습 데이터의 77%가 한 업종에 편중돼 다른 업종 브랜드의 예측력이 크게 떨어지는 문제 확인 → 업종별 표본 불균형을 보정하는 가중치를 도입, 편중이 심한 업종의 성능을 일부 낮추는 대신 소수 업종 성능을 뚜렷이 끌어올리는 균형점을 채택
- 진짜 매장 단위 실측 생존/폐업 라벨(별도 트랙)에도 같은 매장별 신호를 적용해 교차 검증 → 셀 집계 타겟에서만 통하는 게 아니라 실제 매장 결과에도 유효함을 확인

## 4. 최종 모델 및 성능 평가

- 최종 구성: 브랜드 공통 정보 + 경쟁밀도·배후인구·상권변화지표·추정매출·유동인구(3종)·행정동 소비지출(2종), 그래디언트 부스팅 회귀 + 업종 표본 불균형 보정 가중치
- 정확매핑 대형 브랜드 기준(누수 없는 재평가): 예측오차 베이스라인 대비 개선, 순위상관 약 0.59~0.63 — 업종 균형 가중치 적용 전(0.71~0.79)보다는 낮아졌으나 이는 다른 업종 성능 개선을 위해 의도적으로 감내한 트레이드오프
- 요인 중요도: 상권변화지표·행정동 소비지출·추정매출·유동인구가 상위권을 나눠 차지, 브랜드 공통 정보의 기여도는 상대적으로 낮음
- 업종 균형 가중치 적용 후: 편중 업종 외 브랜드(서양식/일식/중식)의 순위상관이 처음으로 통계적 유의수준까지 개선됨
- 근사매핑 소형 브랜드(매장 9곳)에도 동일 피처 적용 시 순위상관 약 0.60~0.74 — 여전히 통계적으로 유의미하나 표본이 작아 확정적 결론은 이름
- 실 배포용 스코어링 인터페이스(주소 입력 → 위험 점수 출력) 구축 완료, 실제 주소로 동작 확인
- 실 배포 시 본사가 보유한 실제 가맹점별 매출로 매출 피처를 교체할 수 있는 구조를 마련해둠 — 가상 매출로 진행한 민감도 분석(시뮬레이션, 실측 아님)에서는 실제 매출의 신호력이 충분히 강할 경우 순위상관이 추가로 오를 여지가 있음을 확인
- 한계: 상권 배정이 좌표 기반 근사치, 매출 피처는 크로스워크 근사 매핑 브랜드에서 신뢰도가 낮아질 수 있음, 서울 지역 데이터에 한정, 신규 브랜드의 절대 오차는 순위보다 신뢰도가 낮음
- 결론: 정밀 확률값이 아닌 브랜드 내 매장 간 상대적 위험 순위 참고 지표로 활용 권장
