# 피자스쿨(피자 프랜차이즈) 케이스 스터디

[[1. Projects/폐점 재계약 리스크 조기경보 모델]] — [[3. Resources/폐점 리스크 모델 - 쿠우쿠우 케이스 스터디]]에 이어 두 번째 브랜드 케이스 스터디. 코드: `src/case_study_pizzaschool.py`(저장소).

**참고**: 이 사례는 v1(브랜드 단위 실측 타겟) 모델 기준이다. 서울시 업종분류에 "피자" 카테고리 자체가 없어 v2(서울 CLSBIZ_RT 직접 타겟, [[3. Resources/폐점 리스크 모델 - 모델 정의서 (v2)]] 참고) 대상에는 포함되지 않았음 — 본죽&비빔밥/명동칼국수([[3. Resources/폐점 리스크 모델 - 명동칼국수 케이스 스터디]])처럼 v2 최신 피처(추정매출·유동인구·소비지출)로 재검증된 수치는 없다.

## 왜 피자스쿨인가

업종별로 모델 신뢰도를 다시 살펴본 결과, "피자" 업종이 검증 데이터에서 가장 예측력이 좋았음(순위상관 0.64, 반면 가장 큰 카테고리인 "한식"은 거의 무작위였음). 그중 피자스쿨은 실제 매장이 **964개**(2026-07-23 sbiz 중복 등록 제거 후 수치, 이전 977개)로 압도적으로 많고(쿠우쿠우의 약 11배), **실제 해지율 데이터도 있어서**(2025년 2.5%, 낮은 위험) 쿠우쿠우 사례와 달리 어느 정도 비교 기준점을 가질 수 있음.

## 결과

- 964개 매장 전체에 모델을 적용, 위험 점수 분포가 쿠우쿠우보다 약간 더 넓게 나옴(매장 수가 많아 경쟁밀도 다양성도 큼)
- **뜻밖의 발견 — 경쟁점포 수와 위험도가 단순하지 않은 관계**: 위험도가 가장 높게 나온 매장들은 오히려 주변에 경쟁 피자집이 **하나도 없는** 한산한 곳이었고, 위험도가 가장 낮은 매장들은 주변에 경쟁점포가 **5~9개 있는**(2026-07-23 수치 재확인) 적당히 붐비는 상권이었음
- 즉 "경쟁이 많으면 위험하다"가 아니라 **"너무 한산해도 위험, 너무 붐벼도 위험, 적당한 상권이 가장 안전"**한 U자형 패턴으로 나타남 — 상권에 아예 수요가 없다는 신호일 수도 있고, 반대로 과밀한 경쟁도 위험 신호일 수 있다는 뜻

## 주의할 점

이 U자형 패턴은 피자스쿨 하나의 사례에서 나온 것이라, 다른 브랜드에도 똑같이 적용된다고 단정할 수는 없음 — 하나의 관찰 사례로 취급해야 함.

## 이게 주는 시사점

기존 "위험요인 → 예방조치" 가이드 표의 "경쟁밀도" 항목은 "경쟁이 몰리면 위험하다"로만 서술돼 있었는데, 이번 발견으로 **"상권이 지나치게 한산한 경우도 별도로 점검해야 할 위험 신호"**라는 반대쪽 시나리오도 추가할 필요가 있음.
