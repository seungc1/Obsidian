# 폐점·재계약 리스크 모델 v2 — 최종 보고서 (데이터·계산·모델·의미)

[[1. Projects/폐점 재계약 리스크 조기경보 모델]]의 v2(서울 한정, 매장 단위)를 **어떤 데이터를 썼는지 → 어떻게 계산했는지 → 어떤 모델을 왜 썼는지 → 그래서 무엇을 말해주는지** 순서로 정리한 최종 보고서. 코드 기준(`train_seoul_closure.py`, `seoul_target.py`, `sbiz_competition.py`, `sgis_grid_features.py`, `subway_distance.py`)으로 작성했으며, v1(전국 브랜드 모델)과의 차이는 각 절에서 명시한다.

---

## 0. 이 모델이 답하는 질문

**"같은 프랜차이즈 브랜드 안에서, 서울에 있는 매장 A와 매장 B 중 어디가 상대적으로 더 폐업 위험이 높은가?"**

v1(전국)은 "브랜드 대 브랜드"만 비교 가능했던 한계가 있어(브랜드 정적 정보만으로는 같은 브랜드의 매장을 구분 못 함), v2는 **매장이 위치한 상권의 실측 데이터**를 붙여 이 한계를 구조적으로 해결한 버전이다.

## 2. 어떤 계산방식을 썼는가

### 2-1. 매장 → 상권 배정 (근사)

서울시 상권 마스터(`TbgisTrdarRelm`)는 **상권 경계(폴리곤)가 아니라 중심좌표 + 면적만** 제공한다. 그래서 각 매장을 **가장 가까운 상권 중심점**에 배정한다(BallTree, haversine 거리, k=1 최근접). → 상권이 밀집한 지역에서는 오배정 위험이 있는 근사치라는 한계가 있다.

### 2-2. 매장당 매출 근사

서울시가 주는 매출은 "상권×업종 전체 합계"이지, 매장 개별 매출이 아니다. 그래서:

```
매장당 평균 매출 ≈ (그 상권×업종 셀의 매출 합계) ÷ (그 셀의 점포수)
```

프랜차이즈 본사가 실제 가맹점별 매출을 가지고 있다면 그 값이 우선 사용되도록 오버라이드 경로를 마련해뒀다(현재는 실측치가 없어 항상 근사치 사용).

### 2-3. 경쟁밀도

같은 상권업종소분류에 속한 sbiz 전체 점포를 BallTree(haversine)로 색인하고, 각 매장 기준 반경 250m/500m 안에 몇 개 점포가 있는지 센다(자기 자신 제외).

### 2-4. 지하철 거리 (신규)

서울교통공사 1~8호선 역 276개 좌표를 BallTree로 색인하고, 각 매장에서 **가장 가까운 역 1개까지의 haversine 거리(m)**를 구한다. 9호선·신분당선·공항철도 등 다른 운영사 노선은 미포함 — 그 노선 인근 매장은 거리가 실제보다 멀게(과대) 나올 수 있다.

### 2-5. 학습 가중치 (sample_weight)

작은 상권 셀은 폐업 1건만 생겨도 폐업율이 크게 튀는 노이즈가 있다(예: 점포 3개 중 1개 폐업 = 33%). 이를 완화하기 위해:

```
표본크기 가중 = √(그 셀의 점포수)
업종 균형 가중 = (가장 큰 업종의 표본수 ÷ 그 업종 표본수) ^ 0.5
최종 가중치   = 표본크기 가중 × 업종 균형 가중
```

업종 균형 가중을 넣은 이유: 학습 데이터의 77%가 한식에 편중돼 있어, 그대로 두면 중식·일식·서양식 브랜드의 예측력이 크게 떨어짐(§34/§39 실험으로 확인). power=0.5는 한식 성능을 과하게 희생하지 않으면서 소수 업종을 뚜렷이 개선하는 지점으로 실험 확정.

### 2-6. 업종 크로스워크 (근사)

서울시 자체 업종분류는 음식점 10개뿐이라 sbiz의 세분화된 업종과 정확히 안 맞는 경우가 많다. 정확 매칭(한식/중식/일식/서양식/치킨전문점)과 근사 매칭(예: "구내식당·뷔페"→"한식음식점")이 섞여 있고, **정확 매칭 브랜드일수록 매출 같은 업종 의존 피처의 신뢰도가 높다.** 반대로 유동인구·상권변화지표·행정동 소비지출은 업종과 무관하게(상권·행정동 단위로만) 붙기 때문에 근사 매칭 브랜드에도 안전하다는 게 실험으로 확인됐다(§28).

## 3. 어떤 모델을 썼는가 (그리고 왜)

### 3-1. 최종 모델: LightGBM 회귀

```
LGBMRegressor(
    n_estimators=300, learning_rate=0.08, num_leaves=63,
    min_child_samples=20, subsample=1.0, colsample_bytree=1.0,
    reg_lambda=5.0, reg_alpha=1.0, random_state=42,
)
```

범주형(업종분류, 상권변화등급)은 pandas category dtype으로 넘기면 LightGBM이 자동 인식해 원-핫 없이 네이티브로 처리한다.

### 3-2. 왜 이 모델·이 설정인가 — 검증 과정 (2026-07-28)

1. **8개 알고리즘 동일 조건 비교** (HistGBR·LightGBM·XGBoost·CatBoost·RandomForest·전통GradientBoosting·ExtraTrees·Ridge) → 그 시점 채택 모델이던 HistGradientBoostingRegressor 대비 **LightGBM이 기본 설정만으로 이미 근소 우위**(Spearman 0.553 vs 0.545)
2. **알고리즘별 하이퍼파라미터 랜덤서치**(각 20회) → LightGBM이 Spearman 0.731까지 격차를 벌림(RandomForest가 0.725로 근접 2위)
3. **20개 시드 반복 재검증** (v2는 학습/검증 분할 자체가 `train_test_split`의 무작위 추출이라, 시드마다 분할까지 다시 만들어 재현) → **LightGBM이 20/20 시드 전부 승리**, Wilcoxon 부호순위검정 p<0.0001(우연이라면 이런 결과가 나올 확률이 사실상 0)

|                   | 기존(HistGBR) | 신규(LightGBM)     |
| ----------------- | ----------- | ---------------- |
| Spearman(20시드 평균) | 0.518       | **0.718**        |
| RMSE(20시드 평균)     | 6.22        | **5.55**         |
| 시드 간 표준편차         | 0.016       | 0.018 (비슷하게 안정적) |

### 3-3. 학습/검증 방식

- 분할: `train_test_split(test_size=0.2, random_state=42)` — v1(연도 기반 시간 홀드아웃)과 달리 v2 타겟은 특정 연도에 묶이지 않아 무작위 분할 사용
- 표본: 서울 + 크로스워크 매핑 가능 매장 14,239건 중 실측 타겟이 붙는 13,515건
- 해석: SHAP(Permutation Explainer, 범주형은 정수 코드로 인코딩 후 카테고리로 복원하는 wrapper 사용)으로 피처별 기여도 계산

## 4. 이게 어떤 의미를 가지는가

### 4-1. 무엇을 예측하는가 (그리고 무엇을 예측하지 않는가)

- 산출물은 **매장 단위 상대적 위험 순위**다. "이 매장은 폐업확률 12%"처럼 절대 확률로 읽으면 안 된다.
- 같은 브랜드 안에서 매장끼리 비교할 때 가장 신뢰도가 높다(원래 설계 목적).

### 4-2. 위험을 가장 잘 설명하는 요인 (SHAP 기여도 순)

| 순위  | 요인                   | 의미                           |
| --- | -------------------- | ---------------------------- |
| 1   | 상권 추정 매출 수준          | 그 상권·업종의 평균 매출이 낮을수록 위험      |
| 2   | 상권변화지표(폐업 추세)        | 서울 평균보다 폐업이 잦은 상권일수록 위험      |
| 3   | 유동인구(점심 시간대)         | 점심 유동인구가 적을수록 위험             |
| 4   | 행정동 음식 소비지출          | 그 동네 주민의 외식 지출이 적을수록 위험      |
| 5   | 유동인구(총량/저녁)          |                              |
| 6   | 지하철역까지 거리            | 역에서 멀수록 위험 (신규 반영 피처, 8/27위) |
| 7   | 배후인구, 경쟁밀도           |                              |
| 8   | 브랜드 고유 정보(계약조건·비용 등) | 기여도 상대적으로 낮음                 |

**핵심 해석**: 서울 매장의 폐업 위험은 "어떤 브랜드인가"보다 "어디에 있는가"가 압도적으로 더 크게 좌우한다. v1(전국)에서 브랜드 정적 정보와 업종 평균이 중요했던 것과 대조적 — 상권 단위 실측 데이터가 붙으면서 입지 요인이 전면에 드러났다.

### 4-3. 실무 적용 — 위험요인별 대응

| 위험요인 | 예방조치 | 재계약 조항 |
|---|---|---|
| 상권 매출 침체 | 매출 모니터링 주기 단축, 조기 개입 | 상권 등급 재평가 후 갱신조건 조정 |
| 상권 자체 쇠퇴 추세 | 침체 지역 매장 우선 지원(마케팅/리뉴얼) | 상권 재평가 연동 조항 |
| 유동인구 저조 | 배달·픽업 등 대안 채널 강화 | — |
| 지하철 접근성 낮음 | 배달 인프라 투자 우선순위 상향 | 임대료 조건 재검토 |
| 경쟁 밀집 | 포지셔닝 차별화, 신규 출점 시 사전 검토 | 반경 내 동일업종 신규 출점 제한 강화 |

### 4-4. 믿어도 되는 범위 / 안 되는 범위

- **믿을 만함**: 업종이 정확히 매칭되는 대형 브랜드(매장 100개 이상), 유동인구·상권변화지표·소비지출 같은 업종 무관 신호
- **주의 필요**: 업종이 근사 매칭된 브랜드(예: 뷔페→한식으로 취급), 매장 9곳 이하의 소규모 브랜드, 매출 피처(근사 매칭 브랜드에서 오히려 역효과 확인됨)
- **적용 불가**: 서울 외 지역 — 다른 지자체는 이 정도 실측 데이터를 API로 못 받아 v2 방식 자체가 성립하지 않음(v1으로 대체)

## 5. 요약 한 줄

**서울 매장의 상권 실측 데이터(매출·유동인구·상권변화지표)를 LightGBM으로 학습시켜, 같은 브랜드 안에서 어느 매장이 입지상 더 위험한지 순위를 매기는 모델.** 20개 시드 반복 검증으로 기존 대비 확실한 성능 우위(Spearman 0.52→0.72)를 확인했고, 핵심 결론은 "브랜드보다 입지가 지배적"이라는 것.

- **v1+v2 결합 판단** (`src/combine_scores.py`): 서울 매장은 v1(백분위)+v2(백분위)를 2x2 매트릭스(고위험/업종위험/입지위험/안전)로 결합. v1/v2 각자 독립적으로도 그대로 사용 가능
- **재계약 조항 추천** (`src/clause_recommendation.py`, `risk_clause_map.py`): 개별 매장 SHAP 근거로 예방조치·조항 후보 제시, 방향 확인(`expected_direction`) 자동 경고 포함
- **47개 브랜드 전수 재검증**: 이 문서의 LightGBM 교체 이후 케이스 스터디 재실행 결과, 전체 브랜드 Spearman 범위가 0.11~0.91→0.59~0.98로 대폭 개선(상위 10개 전부 한식) — 자세한 내용 [[3. Resources/폐점 리스크 모델 - 케이스 스터디 종합]]
