# OhDomi 프로젝트 - 전체 서비스 설명자료 (코치 질문 대비)

2026-08-11 세션에서 프론트엔드(OhDomiReact)·백엔드(OhDomiSpring)·리스크 모델(closure-risk-model)을 3개 에이전트로 병렬 전수조사해서 만든 종합 설명자료. 화면마다 어떤 기능이 있고, 어떤 API를 부르고, 화면에 보이는 숫자 하나하나가 실제로 어떻게 계산되는지(이름과 실제 계산이 다른 부분 포함)를 요약·축약 없이 담았다. 코치 예상 질문 시나리오(아키텍처/모델 방법론/데이터·더미데이터/보안/한계 5개 카테고리)까지 포함.

**아티팩트 링크**: https://claude.ai/code/artifact/5d8f24c8-fc9a-46cc-bb3c-7aa9b387000d

## 문서 구성
1. 시스템 개요 (React+Spring+FastAPI 3계층 구조, Vite 프록시 경로, 역할별 접근 화면)
2. 로그인·인증 (세션/CSRF/캡차/비밀번호 해싱 등 백엔드 상세)
3. 가맹점주 화면 6개 전체 — 발주 관리(`StoreSalesOrder`)가 유일하게 API 미연동(전부 프론트 더미)이라는 점 명시
4. 관리자 화면 9개 전체 — 매출 분석의 "30일 롤링 vs 전체 누적 기간 불일치" 등 실제 계산 오차 포함
5. Spring 백엔드 컨트롤러 11개 전체(SQL 쿼리·계산식·DB 스키마)
6. closure-risk-model 방법론 전체 — v1(랜덤포레스트)/v2(LightGBM) 모델, SHAP 근거 생성 방식, 백분위의 정확한 의미, 2x2 종합판정 로직, 예상매출액 산정서 법정 계산법, 현재 남아있는 더미데이터 전체 목록
7. 숫자·용어 사전
8. 코치 예상 질문 시나리오 + 답변

## 참고
- 원본 마크다운은 대화 세션의 임시 작업 디렉터리에만 있고 vault에는 저장하지 않음 — 위 아티팩트 링크가 유일한 사본. 필요하면 아티팩트를 다시 열어 텍스트를 vault로 옮길 수 있음.
- 이 문서가 조사한 코드 스냅샷 시점 이후의 변경사항은 반영되지 않음(2026-08-11 세션 기준).
