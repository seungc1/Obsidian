# 폐점·재계약 리스크 조기경보 모델 — 발표자료

[[1. Projects/폐점 재계약 리스크 조기경보 모델]] 최종 리포트(`docs/report.md`, 코드 저장소)를 팀 발표용으로 정리한 슬라이드 텍스트본. 원본 상세 근거는 `docs/design.md`(실험 로그 전체) 참고.

---

## 1. 타이틀

**폐점·재계약 리스크 조기경보 모델**
브랜드 단위 실측 데이터로 진단한 위험 신호와, 예방조치·재계약 조항 설계를 위한 가이드

팀 미니프로젝트 · 데이터 수집·모델링 · 최종 리포트 2026-07-23

---

## 2. 목적

이 모델은 왜 만드는가

- 프랜차이즈 본사가 가맹점 관리 차원에서 **개별 가맹점의 폐업확률**을 파악하고, 이를 근거로 예방조치와 재계약 조항을 설계하는 데 쓰기 위함
- 단순 예측 정확도 자체보다 **해석 가능성**이 필수 요구사항 — SHAP으로 "이 위험이 왜 높은지"를 요인별로 분해해 제시
- 개별 점포 맞춤 리포트가 아니라, 위험요인 카테고리별 **"예방조치/재계약 조항" 일반론 가이드**를 최종 산출물로 포함

---

## 3. 데이터 & 타겟

브랜드x연도 단위 실측 해지율

공정거래위원회 가맹사업 정보공개서 `1112`(가맹점 변동 현황)에서 추출한 브랜드x연도 실측치를 타겟으로 직접 사용한다.

> `discontinuation_rate = (계약종료수 + 계약해지수) / 연초가맹점수`
> 1.0으로 클립 · 브랜드x연도 14,244행 중 타겟 계산 가능 3,951행(평균 15.4%)

**한계**: 개별 가맹점 단위가 아니라 **브랜드 단위 집계 실측**이다 — 개별 점포 원자료(가맹점목록현황)는 COUNT 집계만 노출돼 구조적으로 확보 불가능했다.

## 4. 모델링 여정 — 8단계, 실패와 반증의 기록

| #   | 단계                       | 결과                                                   |
| --- | ------------------------ | ---------------------------------------------------- |
| 01  | Cell(지역×업종) 매크로 프록시      | 서울 실측 대비 상관관계 사실상 없음(R²<0.01) → 폐기, 브랜드 실측 타겟으로 전환   |
| 02  | 브랜드 실측 + 정적 피처           | Spearman 0.037 → 피처 부족으로 판단                          |
| 03  | + 브랜드 개별 시계열 피처          | Spearman 0.084, RMSE는 오히려 악화 → 신규 피처 전부 SHAP 기여도 0   |
| 04  | 타겟 노이즈 진단 + 표본크기 가중      | 가중+대형브랜드 서브셋 Spearman 0.158 → 가중회귀를 기본값으로 채택         |
| 05  | 미활용 데이터 재처리 + imputation | 커버리지 100%까지 올렸지만 신규 피처 여전히 SHAP 0 → 개선은 전부 가중 효과였음   |
| 06  | 정규화 튜닝                   | Spearman 0.161, RMSE 0.2415 → "과의존" 우려가 반증되고 최종모델 확정 |
| 07  | 브랜드↔가맹본부 매핑(재무/법위반 연결)   | 매핑 10%만 성공, SHAP 전부 0 → 매핑 방법의 한계, 가설 자체는 미검증        |
| 08  | sbiz 경쟁밀도(반경 250m/500m) 추가 | RMSE 0.2354(베이스라인 첫 승리), Spearman **0.1653**(최고 기록) → 최종 피처셋 확정 |

## 5. 최종 성능 — 순위는 분별하지만, 정확도는 약하다

| 지표            | 값          | 비고                                                   |
| ------------- | ---------- | ---------------------------------------------------- |
| RMSE          | **0.2354** | 평균값 예측 베이스라인 0.2386 대비 **1.3% 개선 — 처음으로 베이스라인을 이김** |
| MAE           | 0.1740     | n_train 1,931 / n_valid 1,892 (2024→2025 시간 기반 홀드아웃) |
| Spearman 순위상관 | **0.1653** | 여정 초기 0.037에서 개선 — 이 프로젝트 전체 최고 기록, 그래도 절대적으론 약함    |

> 개선됐지만 여전히 절대적으로는 약한 모델이다. 아래 SHAP·가이드 표는 **정밀한 점수가 아니라 방향성 참고자료**로 해석해야 한다.

## 6. SHAP 피처 중요도 — 업종 피어 신호가 압도적 1위

| 순위 | 피처 | mean\|SHAP\| |
|---|---|---|
| 1 | 업종 피어 평균 해지율 | 0.0339 |
| 2 | 이행보증금 등 | 0.0169 |
| 3 | 경쟁밀도(반경 250m) | 0.0143 |
| 4 | 업종중분류 | 0.0131 |
| 5 | 인테리어비용 | 0.0119 |
| 6 | 기타 가맹비용 | 0.0109 |
| 7 | 보증금 | 0.0107 |
| 8 | 경쟁밀도(반경 500m) | 0.0095 |
| 9 | 평당 인테리어비용 | 0.0090 |

브랜드 개별 시계열 피처(전년 해지율·규모증감·신규개업·등록취소이력) + 가맹본부 재무·법위반 10종은 전부 SHAP 기여도 0 — 여러 차례 검증해도 예측 관계 없음으로 결론. 경쟁밀도는 sbiz 상가업소 데이터에서 상호명 매칭으로 브랜드의 실제 점포를 찾아(85% 매칭) 계산 — 처음으로 지리적 신호가 순수하게 기여했다(매칭점포수 자체는 경쟁밀도가 아니라 브랜드 규모 대리신호로 판명돼 제외).

## 7. 핵심 산출물 — 위험요인 → 예방조치 / 재계약 조항

| 위험요인 카테고리 | 근거 | 예방조치 | 재계약 조항 |
|---|---|---|---|
| **업종 구조적 위험**(같은 업종 다른 브랜드들도 해지 중) | 강함 · 1위 | 업종 트렌드 정기 모니터링, 업종 내 수요변화 조기경보, 복수 업종·업종전환 상담 제공 | 업종 변경 시 계약 승계·조건 조정 조항 명확화, 최소 매출 기준 재검토 주기 단축 |
| **초기 투자·비용 부담**(이행보증금·인테리어·보증금 등) | 중간 · 2·5·6·7·9위 합산 | 초기비용 회수 기간 시뮬레이션 제공, 비용 부담이 큰 가맹점 대상 재협상 지원 | 회수 미달 시 유예/분할 조항, 인테리어 재투자 주기와 갱신 시점 연동 |
| **경쟁밀도**(반경 250m/500m 내 동일업종 점포 수) | 중간 · 3·8위, 신규 반영 | 경쟁 밀집 지역 가맹점 대상 포지셔닝 차별화 지원, 신규 출점 시 경쟁밀도 사전 검토 | 반경 내 동일업종 신규 출점 제한(상권보호) 조항 강화, 경쟁밀도 급변 시 갱신조건 재검토 |
| **업종 분류**(중분류/대분류 자체 특성) | 중간 · 4위 | 업종별 표준 리스크 관리 템플릿 차등 적용 | 업종 특성을 반영한 표준 재계약 조항 템플릿 |
| **브랜드 업력**(신생 브랜드일수록) | 약함 · 11위 | 개업 초기 밀착 지원(운영 컨설팅·초기 마케팅) | 성장 단계별 갱신조건 차등화, 초기 완화 조건 |
| **계약기간 구조**(최초/갱신 계약연수) | 매우 약함 · 참고용 | — | 갱신주기를 실제 관찰된 리스크(업종/비용/경쟁밀도)와 연동해 재검토 |

## 8. 검증 · 캘리브레이션 · 추론 파이프라인 — DoD 마무리

**decile/lift**: 예측 위험도 10분위 중 최상위 10%의 실측 해지율이 최하위 10%보다 **2.75배** 높음(0.251 vs 0.091) — 실측 해지율이 예측 순위에 따라 완벽히 단조 감소. Spearman(0.165)만 보면 약해 보이지만 극단 그룹 분리력은 실용적.

**subgroup 안정성 — 숨어있던 편차 발견**: 업종별로 쪼개보니 **서비스 업종은 Spearman 0.02**(거의 무작위) — 종합 평균(0.165)이 이 편차를 가리고 있었음. 대형 브랜드(≥10점)는 0.227로 뚜렷이 더 좋음. → **서비스 업종에는 이 모델의 가이드 표를 참고 이상으로 쓰면 안 됨.**

**캘리브레이션**: valid를 반으로 나눠(n=946/946) 적합/홀드아웃 검증 — 홀드아웃 MAE 0.1761→0.1752 개선, 신뢰도 구간에서 보정 전 체계적 편향(저위험 과소추정·고위험 과대추정)이 보정 후 완화됨을 확인.

**추론 파이프라인**(`src/pipeline.py`): 브랜드 피처(비용·계약조건·업종·경쟁밀도 등)를 입력하면 raw/calibrated 위험 스코어를 출력. `python -m src.pipeline --input-json <파일>`로 동작 확인.

## 9. 한계 — 솔직하게 남겨야 할 것들

- **브랜드 단위, 개별 가맹점 단위 아님** — 원래 목표인 점포 단위 예측은 완전히 달성되지 못함
- **예측력이 약함** — RMSE는 베이스라인을 이겼지만 근소한 차이, 순위 정확도(0.165)도 절대적으론 약함
- **업종별 신뢰도 편차** — 서비스 업종은 순위 분별력이 거의 없음(위 8절)
- **표본 크기** — 브랜드 74%가 가맹점 10개 미만, 타겟 분산의 상당 부분이 소표본 노이즈
- **데이터 공백** — 유동인구·임대료(지방 커버리지 없음), 가맹본부 재무·법위반(이름 정확일치 매핑만 10% 성공), 매출(커버리지 1% 미만)
- **경쟁밀도는 단일 시점** — sbiz가 202603 한 시점 스냅샷이라 연도별 변화는 반영 못함
- **캘리브레이션 해상도 낮음** — 홀드아웃 n=946 수준에서 Isotonic 계단함수가 거칢
- **프록시 특성** — 타겟은 실측이나, 등록취소·업종 피어평균·경쟁밀도 등 일부 보조 신호는 여전히 근사치

## 10. 다음 단계 — 아직 열려 있는 과제

- 브랜드↔가맹본부 매핑 정교화(현재 이름 정확일치로 10%만 성공) → 재무·법위반 데이터 재검증
- sbiz 매칭을 좌표→행정동 조인까지 확장 — 개별 가맹점 단위 예측에 더 접근(현재는 브랜드 단위 평균값)
- 서비스 업종 전용 서브모델 또는 별도 피처 검토
- 표본 축적 후 캘리브레이션 재검증(해상도 개선)

## 11. 요약

Cell 매크로 프록시는 실패했고, 브랜드 실측 타겟은 약하지만 실재하는 신호를 준다 — **업종 구조적 위험**, **초기 투자부담**, 그리고 새로 확보한 **경쟁밀도**가 가장 신뢰할 수 있는 세 축이다(RMSE가 처음으로 베이스라인을 이기고 Spearman도 최고치 기록). decile 분석·캘리브레이션·추론 파이프라인까지 완료해 계획했던 모델링 작업은 마무리됐으나, **서비스 업종에는 신뢰도가 낮다는 편차**가 새로 발견됐고, 개별 가맹점 단위 예측을 완성하려면 경쟁밀도의 점포 단위 확장과 본부 재무 매핑 정교화가 다음 관문이다.
