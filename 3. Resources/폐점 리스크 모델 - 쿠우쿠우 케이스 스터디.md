# 쿠우쿠우(뷔페 프랜차이즈) 케이스 스터디

[[1. Projects/폐점 재계약 리스크 조기경보 모델]]을 쿠우쿠우 전용으로 좁히는 재설계 검토 중, 완성된 일반 모델을 쿠우쿠우 실제 매장에 적용해본 사례 분석. 코드: `src/case_study_kuukuu.py`(저장소).

## 왜 "검증"이 아니라 "적용"인가

쿠우쿠우는 공정거래위원회 데이터에 실제 폐업/해지 실적을 계산할 원본 수치가 없어서, 우리 모델을 이 브랜드로 "맞는지 확인"할 수는 없음. 대신 이미 완성된 모델을 실제 매장 91곳에 적용해서 "이 모델대로라면 어느 매장이 더 위험하게 나오는지" 살펴보는 사례 분석임.

## 데이터

- sbiz 상가업소 데이터(2026년 3월 기준)에서 실제로 확인된 쿠우쿠우 매장 **86개**(2026-07-23 sbiz 중복 등록 제거 후 수치, 이전 91개)
- 비용·계약조건 등 브랜드 공통 정보는 전 매장에 동일 적용, 매장마다 다른 건 **주변 경쟁점포 수**뿐

## ⚠️ 미리 알아둘 점

공정거래위원회 데이터에는 쿠우쿠우가 "일식(초밥)" 업종으로 등록돼 있음(실제로는 뷔페). 모델이 참고하는 "업종 평균 위험도"는 그래서 뷔페 업계가 아니라 초밥집들과 비교한 값임 — 주변 경쟁점포 수는 이 문제와 무관하게 정확히 계산됨.

## 결과

- 매장 간 위험 점수 차이가 **매우 작음** — 대부분 매장이 거의 같은 점수로 나옴
- **가장 위험하게 나온 매장**: 경기도 동탄점 — 주변 250m 안에 같은 업종 경쟁점포가 19개(다른 매장은 대부분 0~1개)로 유독 밀집한 상권(2026-07-23 중복 제거 후 수치, 이전 22개)
- 나머지 매장 대부분은 주변 경쟁점포가 거의 없는 한산한 위치

## 이게 보여주는 진짜 의미

매장 간 차이가 거의 안 나는 이유는, 비용·계약조건·업종분류 같은 값이 **모든 매장에 똑같이 적용**되기 때문임 — 오직 "주변 경쟁점포 수" 하나만 매장마다 다름. 즉 지금 모델은 "브랜드가 같으면 매장 하나하나를 구분하지 못한다"는 한계를 이 사례에서 그대로 확인한 셈. 개별 가맹점 단위로 제대로 구분하려면 매장마다 실제로 다른 정보(유동인구, 임대료, 매출 추이, 매장별 개업일 등)가 더 필요함.

## 추가 확인: 서울 매장에 유동인구 데이터를 더해보니

"매장마다 실제로 다른 정보가 더 필요하다"는 위 결론을 실제로 시험해봄 — 서울시가 공개하는 유동인구 데이터를 서울 소재 매장(91개 중 9개, 서울은 이 데이터만 제공)에 연결.

- **유동인구는 확보 성공**: 9개 매장의 상권별 유동인구가 4.2만 명~268만 명으로 **최대 63배 차이** — 매장 위치에 따라 확실히 다른 신호가 있음을 확인(건대입구역 매장이 최고, 고척중학교 인근 매장이 최저)
- **매출 데이터는 실패**: 이 데이터셋 자체에 "뷔페"라는 업종 카테고리가 없어서 매출은 못 가져옴 — 공공데이터마다 업종을 나누는 기준이 제각각이라는 문제가 여기서도 또 발견됨
- 다만 서울 매장만 10%라 이 정보를 모델 재학습에는 반영하지 않고, 서울 9개 매장에 대한 참고 정보로만 남겨둠
- (부수적 발견) sbiz 원본 데이터에 "쿠우쿠우동탄" 매장이 지역 표기가 다르게(경기도/서울특별시) 두 번 등록돼 있음 — 데이터 자체의 오류이거나 실제로 다른 두 지점일 수 있어 추가 확인이 필요함. **2026-07-23 후속 조치**: 이 발견을 계기로 sbiz 274만 건 전수 점검을 진행해 같은 상호명+좌표가 완전히 일치하는 진짜 중복 93,129건(3.4%)을 찾아 제거함(쿠우쿠우 매장 수가 91→86개로 줄어든 이유). 다만 "쿠우쿠우동탄"처럼 좌표까지 다른 이종 중복은 이 규칙으로 자동 판단이 안 돼 여전히 두 건 다 남아있음

**결론**: 유동인구 하나만 추가해도 매장 간 차이가 크게 벌어지는 걸 확인했음 — "매장별 차별화 데이터가 있으면 확실히 도움된다"는 가설은 맞았지만, 지역 커버리지(서울 한정) 문제로 지금 당장 전체 모델에 반영하기는 어려움.

## 추가 확인: 추정매출 피처를 v2 모델에 반영해보니 (2026-07-23)

이후 서울 실측 폐업율을 직접 타겟으로 쓰는 v2 모델([[3. Resources/폐점 리스크 모델 - 케이스 스터디 종합]] 참고)에 서울시 추정매출-상권 데이터를 매장별 신호로 추가하는 실험을 진행. **본죽&비빔밥(업종 분류가 정확한 브랜드)에서는 예측-실측 순위상관이 뚜렷이 개선(0.460→0.598)됐지만, 쿠우쿠우에 그대로 적용하니 오히려 악화됨(0.481→0.289)**.

- 원인: 쿠우쿠우는 공정위/서울시 데이터 어디에도 "뷔페" 카테고리가 없어서 "구내식당·뷔페"를 "한식음식점"으로 근사 매핑해서 씀 — 그래서 이 매출 피처가 실제로는 뷔페 매출이 아니라 **인근 한식당 평균 매출**을 대신 반영함
- 정확한 업종 매칭(본죽&비빔밥=한식↔한식)에서는 이 근사가 진짜 신호로 작동했지만, 근사 매칭(쿠우쿠우=뷔페→한식)에서는 노이즈로 작용한 것으로 보임
- **시사점**: "매장마다 실제로 다른 정보가 더 필요하다"는 위 결론이 무조건 맞는 게 아니라, **업종 분류가 정확히 매칭되는 브랜드에서만 새 피처 추가가 도움이 된다**는 조건이 붙는다는 걸 이번에 처음 확인 — 쿠우쿠우처럼 업종 자체가 잘못 분류된 브랜드는 새 데이터를 추가할수록 오히려 왜곡될 위험이 있음

## 추가 확인: 유동인구 피처를 v2 모델에 반영해보니 (2026-07-24)

매출 피처는 쿠우쿠우에서 악화됐지만(위), 이어서 서울시 **유동인구(길단위인구-상권)**를 v2 모델에 추가하니 이번엔 **뚜렷이 개선**됨 — 예측-실측 Spearman이 0.481(매출 반영 전)→0.289(매출 반영, 악화)→**0.804(유동인구 반영, p=0.0089)**로, 쿠우쿠우 케이스 사상 처음으로 통계적으로 유의미한 결과가 나옴.

- 원인: 유동인구는 매출과 달리 업종 분류를 거치지 않고 상권(`trdar_cd`) 단위로만 붙는 데이터라서, 쿠우쿠우의 "구내식당·뷔페→한식음식점" 근사 크로스워크 문제와 아예 무관함
- 특히 실측 최고 위험 매장(구로점 추정, 폐업율 50%)은 매출 데이터가 결측이었는데도 유동인구 값(다른 매장 대비 최저치)만으로 예측 1위로 정확히 식별됨
- **시사점**: "업종 분류가 부정확한 브랜드는 새 데이터를 추가할수록 위험하다"(위 매출 피처 사례의 교훈)는 무조건적인 규칙이 아니라, **그 피처 자체가 업종 크로스워크에 의존하는가**에 달려 있다는 걸 확인 — 크로스워크 의존이 없는 피처(상권 단위, 업종 무관)라면 쿠우쿠우처럼 업종이 잘못 분류된 브랜드에도 안전하게 적용 가능함
