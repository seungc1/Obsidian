# 폐점·재계약 리스크 모델 — 코드 파일 구성

[[1. Projects/폐점 재계약 리스크 조기경보 모델]]의 코드 저장소(`C:\Users\yooyj\projects\closure-risk-model`, 별도 git repo) 구조 정리. 실제 코드는 vault에 복사하지 않고 이 문서에서 경로/역할만 참조.

## 요약 (핵심 3줄)
1. 노트북(`01`~`06`)이 수집→EDA→라벨링→피처→모델링→검증의 실행 순서를 그대로 나타냄
2. `src/`는 노트북에서 재사용할 로직(API 클라이언트, 피처, 모델, 추론 파이프라인)을 담당
3. API 키는 `.env`(git 제외)에만 저장하고 `docs/api_keys.md`에 상태만 기록 — 실제 값은 vault에도 절대 적지 않음

## 전체 구조

```
closure-risk-model/
├── .env                  # 실제 API 키 (git-ignored, vault에도 기록 안 함)
├── .env.example          # 키 변수명 템플릿 (실제 값 없음)
├── .gitignore
├── README.md             # 프로젝트 개요, 실행 순서, 핵심 한계
├── requirements.txt      # pandas, lightgbm, lifelines, requests, dotenv 등
├── docs/
│   ├── design.md         # 레이블링 전략·데이터소스·피처·모델링·검증·마일스톤 설계 문서
│   └── api_keys.md       # API별 발급 상태·엔드포인트·테스트 커맨드 (키 값 제외)
├── data/
│   ├── raw/              # 원본 다운로드, 소스별 하위 폴더로 분리
│   │   ├── sbiz/         # 소상공인시장진흥공단 상가업소 데이터
│   │   ├── nts/          # 국세청 휴폐업 현황
│   │   ├── ftc/          # 공정위 정보공개서
│   │   ├── reb/          # 한국부동산원 임대동향
│   │   ├── seoul/        # 서울 열린데이터광장 상권분석
│   │   └── kosis/        # KOSIS 인구통계
│   ├── interim/          # Cell 단위 집계 중간 산출물
│   └── processed/        # 학습용 최종 피처테이블
├── notebooks/
│   ├── 01_data_collection.ipynb      # 공공데이터 API 수집
│   ├── 02_eda.ipynb                  # 탐색적 분석
│   ├── 03_label_construction.ipynb   # Cell 단위 프록시 라벨 생성
│   ├── 04_feature_engineering.ipynb  # 피처 테이블 생성
│   ├── 05_modeling.ipynb             # 모델 학습/캘리브레이션
│   └── 06_validation.ipynb           # decile/calibration 검증
├── src/
│   ├── config.py                     # 경로·Cell 정의·API 키(.env 로드)·엔드포인트
│   ├── data/
│   │   ├── sbiz_client.py            # 상가업소 API 클라이언트 (구현됨, 동작 확인)
│   │   ├── nts_client.py             # 국세청 휴폐업 조회 (스텁, 키 발급 후 구현)
│   │   └── ftc_client.py             # 정보공개서 조회 (스텁, 키 발급 후 구현)
│   ├── features/
│   │   └── build_features.py         # 상권활력도/경쟁밀도/유동인구/임대료/base rate 피처 (스텁)
│   ├── models/
│   │   └── train.py                  # LightGBM 학습 + 캘리브레이션 (스텁)
│   └── pipeline.py                   # 신규 점포 -> 위험 스코어 CLI 엔트리포인트 (스텁)
├── models/                # 학습된 모델 아티팩트 (.pkl 등, git-ignored)
├── reports/
│   └── figures/           # 최종 리포트용 그림
└── tests/
    └── test_pipeline.py   # pipeline.py 스모크 테스트
```

## 데이터 확보 현황 (2026-07-21)

`data/raw/sbiz/`에 전국 17개 시도 상가업소 CSV(기준연월 `202603`, 약 274만 건) 다운로드 완료. **단, 이 파일은 개폐업 이력이 아니라 특정 시점 스냅샷**이라 폐업 추정에는 다른 시점 스냅샷과의 diff가 필요함 — 자세한 내용은 [[3. Resources/폐점 리스크 모델 - 공공데이터 소스 목록]] 및 `docs/design.md`의 "B 소스 방법론 수정" 참고. 과거 시점 스냅샷 추가 다운로드가 다음 선행 작업.
