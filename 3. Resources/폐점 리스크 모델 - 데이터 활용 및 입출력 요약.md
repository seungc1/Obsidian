## v1 — 전국 브랜드 단위 모델

- **모델**: RandomForestRegressor(2026-07-28, HistGradientBoostingRegressor에서 교체 — 8개 알고리즘 비교+튜닝+20시드 재검증으로 확정, 18/20 시드 승리)
- **입력**: 계약기간, 업종 분류, 브랜드 업력, 초기비용 구조(보증금/인테리어비/교육비 등), 업종×연도 피어 평균 해지율, 경쟁밀도(반경 250m/500m), SGIS 배후인구. 지하철거리는 시도했으나 전국 스코프에선 노이즈로 작용해 **제외**
- **출력**: 브랜드×연도 단위 **폐업+재계약실패 통합 리스크 점수**(0~1, 캘리브레이션 후 실제 해지율에 가깝게 보정)
- **성능**: RMSE 0.2355(평균값 예측 대비 근소 우위), Spearman 0.1750(seed=42 기준) — 20개 시드 평균으로는 기존 HistGBR(0.1195)보다 뚜렷이 개선된 0.1531
- **주의**: 서비스 업종은 순위분별력 거의 없음 — 업종별 신뢰도 편차 큼

## v2 — 서울 한정 매장 단위 모델

- **모델**: LightGBM(2026-07-28, HistGradientBoostingRegressor에서 교체 — v1과 동일 절차, 20/20 시드 전부 승리·p<0.0001로 v1보다 더 명확)
- **입력**: 경쟁밀도(250m/500m), SGIS 배후인구, 상권변화지표 등급, 추정매출(업종 정확매핑 시), 유동인구(총량/점심/저녁), **지하철역까지 거리**(2026-07-28 신규 채택)
- **출력**: 매장 단위 **상대적 폐업 위험 순위**(같은 브랜드 내 매장 비교용, 절대 확률 아님)
- **성능**: 테스트 RMSE 5.835(베이스라인 6.952). **2026-07-28 47개 브랜드 재검증**: Spearman 범위가 0.11~0.91(HistGBR)→0.59~0.98(LightGBM)로 대폭 개선, 상위 10개 전부 한식 — 자세한 내용은 [[3. Resources/폐점 리스크 모델 - 케이스 스터디 종합]]
- **핵심 원칙**: 업종 크로스워크에 의존하지 않는 피처(유동인구, 상권변화지표, 지하철거리)일수록 근사매핑 브랜드에도 안전 — 매출처럼 업종 의존 피처는 근사매핑에서 역효과 가능

## v1+v2 결합 및 조항 추천 (2026-07-28 신규)

- `src/combine_scores.py`: 서울 매장은 v1(백분위)+v2(백분위)를 2x2 매트릭스(고위험/업종위험/입지위험/안전)로 결합. 서울 외 지역은 v1만 자동 사용
- `src/clause_recommendation.py`: 개별 브랜드/매장 SHAP 기여도 상위 요인 → 예방조치·재계약 조항 후보 제시. 값이 실제로 "위험한 방향"에 있는지 배경표본과 비교해 자동 경고(`⚠️ 방향 확인 필요`)
- 둘 다 v1/v2 파이프라인을 호출만 하는 애드온이라, 이 기능 없이도 v1·v2는 각각 그대로 사용 가능

## 실사용 예시

```
python -m src.pipeline --input-json <파일>          # v1: 브랜드 dict/주소 -> raw/calibrated 스코어
python -m src.pipeline_seoul --input-json <파일>     # v2: 매장 주소+업종(+브랜드명) -> 스코어
python -m src.combine_scores --input-json <파일>     # v1+v2 결합 2x2 판단
python -m src.clause_recommendation --input-json <파일>  # 위험요인 -> 조항 후보 추천
```
- **입력 JSON**: 브랜드 피처 dict(계약기간·업종·비용 등) 또는 `address`(+선택적 `sbiz_category`) — 주소만 주면 좌표변환→경쟁밀도 자동 계산
- **출력**: raw score(모델 원점수) + calibrated score(보정된 확률형 점수, v1만)
