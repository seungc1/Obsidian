# 모델 정의서 (v1) — 전국 프랜차이즈 브랜드 단위 폐업 리스크 모델

## 1. 모델 설명

- 타겟: 브랜드×연도 폐업률 (계약종료+계약해지 건수 / 연초 가맹점 수, 정보공개서 실측치)
- 입력 데이터: 브랜드 정형 정보(가맹비용·계약기간·업종분류) + 지리 정보(경쟁점포 밀도·배후인구)
- 모델: 그래디언트 부스팅 회귀 알고리즘
- 학습 방식: 시간 기반 홀드아웃(과거 연도 학습 → 이후 연도 검증), 가맹점 수 기반 가중치 적용
- 해석: 요인 중요도 분석으로 위험 요인별 기여도를 함께 제공

## 2. 초기 결과 및 평가

- 지역×업종 단위 거시 통계 조합 라벨 시도 → 실측 대비 상관관계 없음, 폐기
- 브랜드 실측 타겟 전환 후 정적 정보만 사용한 1차 모델 → 예측오차 베이스라인과 거의 동일, 순위상관 거의 0
- 브랜드 최근 실적 추이(전년 해지율 등) 시계열 정보 추가 → 개선 미미, 신규 정보 기여도 0
- 같은 업종 내 타 브랜드 평균 해지율만 유일한 유효 신호로 확인 → 이후 최적화 방향의 핵심 단서

## 3. 모델 최적화 진행 사항

- 표본 크기 기반 가중치 적용 → 순위상관 개선
- 매출·취소이력 등 데이터 보강 → 성능 기여 없음(개선은 전적으로 가중치 효과였음을 확인)
- 업종 평균 신호 의존도 완화 시도(정규화 강화) → 오히려 성능 저하, 해당 신호가 핵심 유효 신호임을 재확인
- 가맹본부 재무·법위반 이력 연결 시도 → 매칭 비율 낮아 유의미한 개선 없음
- 경쟁점포 밀도 피처 추가 → 최초로 예측오차가 베이스라인을 상회
- 데이터 정제(중복 등록 제거, 매장 식별 오류 수정) → 전 지표 추가 개선

## 4. 최종 모델 및 성능 평가

- 최종 구성: 비용·계약·업종·업종평균·경쟁밀도·배후인구 등 18개 피처, 그래디언트 부스팅 회귀
- 성능: 예측오차 베이스라인 대비 개선(개발 과정 중 유일하게 상회), 순위상관 최고치 기록
- 요인 중요도: 업종 평균 해지율 > 경쟁점포 밀도 > 초기 투자비용 순
- 위험도 상·하위 10분위 비교 시 최상위군 실제 해지율이 최하위군 대비 약 2.6배
- 서비스 업종은 순위 분별력 거의 없음 → 업종별 신뢰도 차등 필요
- 예측 점수 보정 절차 적용 → 체계적 편향 완화
- 결론: 정밀 확률값이 아닌 브랜드 간 상대적 위험 순위 참고 지표로 활용 권장
