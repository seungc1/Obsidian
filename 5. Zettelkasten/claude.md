# 5. Zettelkasten

## 목적과 역할

시간과 무관한 **영구 지식**을 축적하는 "지식 발전소"입니다. PARA(`1~4`)가 마감일과 실행 중심의 작업대라면, 이곳은 프로젝트가 끝나도 사라지지 않는 지식과 통찰을 쌓는 공간입니다.

세 단계 파이프라인으로 구성됩니다: `00. Inbox` → `10. Literature` → `20. Permanent`

## 하위 폴더

- **00. Inbox/**: 빠른 메모, 임시 캡처함
- **10. Literature/**: 책·글·영상 등 원천 자료에서 얻은 문헌 노트 (저자의 생각)
- **20. Permanent/**: 나만의 언어로 재구성한 영구 지식 (내 생각)

각 하위 폴더의 세부 규칙은 해당 폴더의 `claude.md`를 참조합니다.

## 핵심 원칙

1. **참조 우선**: 산출물(Projects 등) 제작 시 이곳의 내용을 복사하지 않고 항상 `[[링크]]` / `![[임베드]]` / `[[노트#^블록ID]]`로 참조. 원본은 Single Source of Truth.
2. **One Idea per Permanent Note**: 퍼머넌트 노트는 하나의 주장/개념만 담음
3. **연결 강제**: 새 퍼머넌트 노트는 최소 2개 이상의 기존 노트와 연결 — 고아 노트 방지
4. **원천과 해석 분리**: Literature(원천)와 Permanent(해석)를 절대 섞지 않음
5. **유기적 진화**: 완벽을 추구하지 않고 연결부터 만들고 점진적으로 정제

## 작업 흐름

```
읽기/생각 → 00. Inbox (빠른 메모)
         → 10. Literature (원천 정리)
         → 20. Permanent (내 생각으로 재구성)
```

- **주 1회**: Inbox 비우기
- **월 1회**: 고아 노트(orphan notes) 확인 및 정리
