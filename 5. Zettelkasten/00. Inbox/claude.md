# 00. Inbox

## 목적과 역할

머릿속에 떠오른 아이디어, 순간적인 메모, 아직 정리되지 않은 생각을 **빠르게 캡처**하는 임시 수집함입니다. Zettelkasten 파이프라인의 첫 관문입니다.

## 어떤 노트가 들어가는가

- 형식에 얽매이지 않은 짧은 메모, 떠오른 질문, 나중에 더 파고들 아이디어
- 아직 원천(Literature)인지 내 생각(Permanent)인지 분류되지 않은 모든 것

## 작업 방식과 규칙

1. **속도 우선**: 완성도보다 빠른 캡처가 목적. 형식·태그·링크를 걱정하지 않고 일단 적기
2. **여기에 머무르지 않음**: Inbox는 종착지가 아니라 대기실. 모든 노트는 결국 `10. Literature/`나 `20. Permanent/`로 이동하거나 삭제되어야 함
3. **주 1회 정리(Weekly Review)**: 쌓인 메모를 검토하여
   - 원천 자료에서 온 것 → `10. Literature/`로 이동
   - 이미 내 생각으로 정리된 것 → `20. Permanent/`로 승격
   - 더 이상 가치 없는 것 → 삭제
4. Inbox에 오래 머무르는 노트가 많다면 정리 주기를 놓치고 있다는 신호
