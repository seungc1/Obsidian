# 20. Permanent

## 목적과 역할

Zettelkasten의 핵심 산출물입니다. 원천 자료를 소화하여 **나만의 언어로 재구성한 영구 지식**을 담습니다. 이 폴더의 노트들이 서로 연결되며 만드는 그물망이 곧 "지식 발전소"의 본체입니다.

## 어떤 노트가 들어가는가

- 퍼머넌트 노트 (`type: permanent`) — 하나의 주장 또는 개념 단위
- 제목은 명사구 또는 완결된 문장 형태 (예: "복리 효과는 시간이 가장 큰 변수다")

## 작업 방식과 규칙

1. `permanent` 템플릿(`6. Templates/`) 사용
2. 필수 속성: `type: permanent`, `related`(관련 노트 목록), `created`
3. **One Idea per Note**: 하나의 노트에는 하나의 주장/개념만. 여러 아이디어가 섞이면 노트를 분리
4. **최소 2개 연결 규칙**: 새 퍼머넌트 노트는 반드시 기존 노트 2개 이상과 `[[링크]]`로 연결 — 고아 노트 금지
5. 원천이 있는 경우 `source`로 `10. Literature/`의 문헌 노트를 링크 (원문 복사 금지)
6. 완벽한 문장보다 **연결이 우선** — 초안 상태로 두고 링크부터 만든 뒤 점진적으로 다듬기
