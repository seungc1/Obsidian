# 6. Templates

## 목적과 역할

전체 Vault에서 사용하는 **노트 템플릿**을 보관하는 폴더입니다. 템플릿을 표준화해 노트 품질과 일관성을 유지하고, Dataview 쿼리가 기대하는 속성(Frontmatter) 스키마를 강제합니다.

## 어떤 노트가 들어가는가

- 폴더별 노트 타입에 대응하는 템플릿 파일: `project`, `area`, `resource`, `literature`, `permanent`, `docs`, `archive` 등
- Templater 문법(`<% tp.date.now() %>` 등)을 사용하는 동적 템플릿

## 작업 방식과 규칙

1. 새 폴더/노트 타입이 생기면 반드시 대응하는 템플릿을 먼저 만들고, 각 폴더의 `claude.md`에서 참조
2. 모든 템플릿은 공통 필수 속성(`type`, `status`, `created`, `updated`, `tags`)을 포함
3. 템플릿 변경 시 이미 생성된 노트에는 소급 적용하지 않음 — 새로 만드는 노트부터 적용
4. 템플릿은 최소한으로 유지: 불필요한 섹션을 미리 만들어두지 않음 (유기적 진화 원칙)
